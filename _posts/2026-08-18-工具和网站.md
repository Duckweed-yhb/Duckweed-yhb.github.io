# 学习工具与网站推荐

## 前言

自学路上，最值钱的往往不是某本书、某个教程，而是**一个靠谱的信息入口**。好的资源站能帮你省下大量试错的时间，让你把精力花在真正的学习上。

这篇整理了我常用或觉得值得收藏的学习工具和网站，按用途分类，附上网站和 GitHub 仓库链接。

---

## 一、CS 自学路线

### CS 自学指南（CSDIY）

- 网站：[csdiy.wiki](https://csdiy.wiki/)
- GitHub：[pkuflyingpig/cs-self-learning](https://github.com/pkuflyingpig/cs-self-learning/)

北大同学维护的 CS 自学路线图，把计算机科学的核心课程（数学、编程、系统、AI 等）系统性地梳理成一条可自学完成的路径。每门课都推荐了公开课视频、教材和作业，是我见过的**最完整、最用心的中文 CS 自学指南**。

### 计算机系学生科协技能引导文档（SAST）

- 网站：[docs.net9.org](https://docs.net9.org/)
- GitHub：[SAST-skill-docers/sast-skill-docs](https://github.com/SAST-skill-docers/sast-skill-docs)

清华大学计算机系学生科协整理的技能引导文档，面向刚入学的同学，从基础工具到进阶技能，循序渐进。适合想系统入门 CS 的同学跟着走一遍。

## 二、大学课程攻略

### 浙江大学图灵班学习指南

- 网站：[zju-turing.github.io/TuringCourses](https://zju-turing.github.io/TuringCourses/)
- GitHub：[ZJU-Turing/TuringCourses](https://github.com/ZJU-Turing/TuringCourses/)

浙大图灵班的课程学习指南，由学长学姐们维护，涵盖图灵班各门课程的学习经验、笔记和资源。如果你想了解顶尖 CS 班的学生是怎么学的，这里是个好窗口。

### 浙江大学竺可桢学院辅学计划

- 网站：[ckc-agc.bowling233.top](https://ckc-agc.bowling233.top/)
- GitHub：[ckc-agc/study-assist](https://github.com/ckc-agc/study-assist)

竺可桢学院的同学发起的辅学计划，分享课程资料和学习心得，帮助学弟学妹少走弯路。

### 浙江大学课程攻略共享计划

- 网站：[qsctech.github.io/zju-icicles](https://qsctech.github.io/zju-icicles/)
- GitHub：[QSCTech/zju-icicles](https://github.com/QSCTech/zju-icicles/tree/master)

浙大同学的课程攻略共享仓库，汇集了大量课程的笔记、试卷和复习资料。类似的"课程攻略共享计划"在很多高校都有，值得先搜搜你们学校有没有。

## 四、操作系统学习与竞赛

### 全国大学生操作系统大赛

- 网站：[os.educg.net](https://os.educg.net/#/)
- GitHub：[github.com/oscomp](https://github.com/oscomp)

面向大学生的操作系统设计竞赛，属于"全国大学生计算机系统能力大赛"的一部分。参赛者需要从零设计并实现一个操作系统内核，是系统方向含金量很高的比赛。

### 清华大学开源操作系统训练营（rCore）

- GitHub：[github.com/learningos](https://github.com/learningos)

由清华陈渝老师、向勇老师于 2020 年发起，宗旨是用 **Rust 语言从零写一个操作系统**（基于 rCore 教程）。训练营全程免费，面向全国高校学生，目前已培养了 4000+ 名参与者。

如果你想深入理解操作系统，与其只看书，不如跟着 rCore 教程亲手写一个内核——这是目前中文世界最好的 OS 实践路线之一。

### 矽望泛在操作系统社区

- 网站：[syswonder.org](https://syswonder.org/#/)

一群系统软件爱好者自发组成的开源社区，用 Rust 实现面向"现场计算"场景（自动驾驶、无人机、具身智能等）的新型操作系统。代表项目有 RuxOS、hvisor 等，适合想了解 Rust 系统编程前沿的同学关注。

## 五、编程入门与算法刷题

### Learn-C

- 网站：[learn-c.org](https://www.learn-c.org/)

交互式的 C 语言学习网站，边学边在浏览器里直接运行代码，无需本地安装环境。教程从最基础的变量、数组讲到指针、结构体，适合零基础快速入门 C 语言，也适合随手练习验证某个语法点。

### 菜鸟教程

- 网站：[runoob.com](https://www.runoob.com/)

老牌的编程入门教程网站，几乎覆盖了所有主流技术：HTML/CSS/JavaScript、Python、C、Java、SQL、Linux 命令……特点是**简单直白、即查即用**，适合零基础快速上手某个语法，也适合当作日常速查手册。

### 洛谷（Luogu）

- 网站：[luogu.com](https://www.luogu.com/)

国内最知名的算法竞赛刷题平台之一，最初面向信息学奥赛（OI），现在也覆盖 ACM 选手和普通算法学习者。题库庞大、题解社区活跃、比赛丰富，从入门到进阶都能找到合适的题目。

如果你在准备算法面试或竞赛，洛谷 + LeetCode 配合使用，基本就够覆盖了。

## 七、网络安全与实战

### NSSCTF

- 网站：[nssctf.cn](https://www.nssctf.cn)

国内知名的 CTF（Capture The Flag，夺旗赛）在线平台，由 NSS 团队自研。名字取自电影《我是谁：没有绝对安全的系统》（No System is Safe）。

平台提供动态靶机、动态积分、动态 Flag、比赛中心、探索工坊（系统化学习路径）和每日一题等功能。对网络安全感兴趣的同学，可以从这里入门。

---

## 八、在线工具

### LatexLive

- 网站：[latexlive.com](https://www.latexlive.com/home)

在线 LaTeX 编辑器，无需本地安装 TeX 发行版，浏览器里就能写 LaTeX、实时预览、导出 PDF。适合临时写个公式、体验 LaTeX，或在没装环境的电脑上应急使用。

### PPDDFF

- 网站：[ppddff.com](https://www.ppddff.com/)

免费的在线 PDF 工具站，提供 PDF 压缩、合并、删除页面、PDF 转 Word（支持 OCR 识别扫描件）等功能。处理日常文档时，不用再装一堆软件，浏览器里点几下就搞定。

---

## 写在最后

这些资源站有个共同点：**由学生自发维护、免费开放、持续更新**。它们的存在本身就是一种开源精神——前人栽树，后人乘凉。

自学既要仰望星空——跟顶尖的课程和项目（CSDIY、rCore、操作系统大赛）；也要脚踏实地——用好手边的工具（菜鸟教程、洛谷、在线工具）把每天的事情做好。

如果你也受益于这些资源，不妨也把自己学校、自己专业的课程攻略整理出来，分享给后来的人。这大概就是知识最好的流转方式。

# 华科开放原子开源俱乐部申请指南

## 前言

华中科技大学开放原子开源俱乐部（HUST Open Atom Open Source Club）欢迎所有热爱开源技术的高校开源爱好者。以下是申请加入的完整流程。

---

## 一、给俱乐部开源仓库提交 PR 且被合并

俱乐部的开源仓库托管在 GitHub 和 AtomGit 上，涵盖多种开源软件，如 `atomgit-cli`、`oh-dsh`、`hust-mirrors`、`pwn.hust.college` 等。

为助力新手同学，俱乐部仓库中会标注 **"good first issue"** 标签的开放议题，难度适中且持续更新。你可以：

1. 挑选感兴趣的 issue，在相应 issue 下留言询问细节，并请求设置为 Assignee
2. 研究解决方案，保持与维护者沟通，及时反馈进度与想法
3. 当你的 Pull Request（PR）被成功合并，你就向加入俱乐部迈出了关键一步

> **注意**：AtomGit 目前仅维护 `atomgit-cli`、`atomgit-skills` 等几个仓库，其余仓库均为 GitHub 组织的只读镜像。若想在其他仓库做贡献，请前往 GitHub。

---

## 二、提交成员信息表

完成开源贡献的同学必须填写成员信息表，并将其发送至邮箱 **opensource@openatom.club**。

关于成员信息表，有几个细节需要注意：

- 俱乐部成员编号可填可不填。若想填写，需确保编号不与已有成员重复。
- 若不填写成员编号，俱乐部会自动为你分配未被占用的最小成员编号。
- 成员信息表位于 `docs` 仓库的俱乐部成员信息目录中，可自行查找并填写。

---

## 三、加入俱乐部 GitHub 组织

俱乐部会根据大家在成员信息表中填写的 GitHub ID 来邀请大家加入。**填写 GitHub ID 时一定要认真检查，保证正确无误**，避免因信息错误而影响加入组织。

---

## 四、俱乐部骨干成员福利列表

成为俱乐部骨干成员后，可享受以下福利：

1. 优先使用俱乐部物理资源（服务器、鸿蒙开发板、鸿蒙 PC 等）
2. 优先使用俱乐部软件资源（不限时腾讯或飞书会议）
3. 优先获得俱乐部报销参与开源活动的名额
4. 优先获得开源实习的推荐名额
5. 优先获得各种开源比赛的指导
6. 优先获得金银湖实验室开源实习（可盖章）岗位名额
7. 获得俱乐部津贴
8. 获得专属俱乐部域名邮箱

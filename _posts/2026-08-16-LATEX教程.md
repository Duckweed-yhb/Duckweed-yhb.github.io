# LaTeX 入门教程

## 前言

很多人第一次听说 LaTeX，会被各种"复杂""神秘"的说法吓退。其实恰恰相反——LaTeX 是一个**优雅但绝不复杂**的工具。它要解决的问题只有一个：让你专注内容，把排版交给程序。

这篇教程结合 [一份其实很短的 LaTeX 入门文档](https://liam.page/2014/09/08/latex-introduction/) 整理而成，用最短的篇幅带你跑通 LaTeX 的核心用法。

---

## 一、环境准备

LaTeX 需要两个东西：**TeX 发行版**（编译引擎）和**编辑器**（写代码）。

| 类型 | 推荐 | 说明 |
|------|------|------|
| TeX 发行版 | TeX Live / MiKTeX | 提供编译程序（XeLaTeX 等） |
| 编辑器 | VS Code / TeXworks | 任何纯文本编辑器都行 |

安装好发行版后，TeX Live 自带 **TeXworks** 编辑器，足够入门使用。Windows 下按 `<Win> + R` 输入 `texworks` 回车即可启动。

> 提醒：Windows 平台上，`.tex` 文件和用到的图片**不要用中文命名**，否则可能因编码问题报错。

---

## 二、第一个文档：Hello, world!

新建一个 `.tex` 文件，输入：

```latex
\documentclass{article}
% 这里是导言区
\begin{document}
Hello, world!
\end{document}
```

用 **XeLaTeX** 编译，你会得到一份只有一行 "Hello, world!" 的 PDF。

理解这几个关键点：

- `\documentclass{article}`：声明文档类，`article` 是最常用的类型
- `%` 开头：注释，不参与编译
- `\begin{document}` 到 `\end{document}`：**文档环境**，只有这里面的内容才会输出
- 反斜杠 `\` 开头的是**控制序列**（命令），它们控制排版效果

## 三、中英文混排

TeX 最初是西方人开发的，原生不支持中文。但现在用 XeLaTeX + `ctexart` 文档类，一行就能搞定中文：

```latex
\documentclass[UTF8]{ctexart}
\begin{document}
你好，world!
\end{document}
```

关键就两点：

1. 文档类从 `article` 换成 `ctexart`
2. 加上 `UTF8` 选项

> 特别注意：`CTeX 宏集` 和 `CTeX 套装` 是两回事。前者是现在应该用的宏包集合，后者是过时的老系统，别搞混了。

## 四、文章组织结构

### 标题、作者、日期

```latex
\documentclass[UTF8]{ctexart}
\title{你好，world!}
\author{Liam}
\date{\today}
\begin{document}
\maketitle
你好，world!
\end{document}
```

`\maketitle` 会按预定格式渲染出标题、作者、日期。

### 章节层级

```latex
\section{一级标题}
\subsection{二级标题}
\subsubsection{三级标题}
\paragraph{四级标题}
\subparagraph{五级标题}
```

### 插入目录

在 `\maketitle` 后加一行 `\tableofcontents`，**编译两次**，就能自动生成目录。

## 五、数学公式（LaTeX 的灵魂）

先加载 `amsmath` 宏包：

```latex
\usepackage{amsmath}
```

数学有两种模式：

**行内模式**（嵌在文字里，用 `$...$` 包裹）：

```latex
质能方程是 $E = mc^2$，这是物理学的基础。
```

**行间模式**（独立成行，用 `\[...\]` 包裹）：

```latex
\[
\int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}
\]
```

常用符号速查：

| 写法 | 效果 | 写法 | 效果 |
|------|------|------|------|
| `\alpha` | α | `\beta` | β |
| `\frac{a}{b}` | 分数 | `\sqrt{x}` | 根号 |
| `x^{2}` | 上标 | `x_{2}` | 下标 |
| `\sum` | 求和 | `\int` | 积分 |
| `\leq` | ≤ | `\geq` | ≥ |

## 六、图片与表格

### 插图

```latex
\usepackage{graphicx} % 导言区加载

\begin{figure}[h]
  \centering
  \includegraphics[width=0.6\textwidth]{figure.png}
  \caption{这是一张图片}
\end{figure}
```

### 表格

```latex
\begin{tabular}{|c|c|}
\hline
姓名 & 成绩 \\
\hline
小明 & 90 \\
小红 & 85 \\
\hline
\end{tabular}
```

`|c|c|` 表示两列居中、带竖线；`\hline` 是横线。

## 七、几个带 TeX 的词

| 词 | 含义 |
|----|------|
| TeX | 排版引擎，一切的基础 |
| LaTeX | 基于 TeX 的宏包集合，最常用 |
| XeLaTeX | 支持 Unicode 和系统字体的编译方式，中文首选 |
| pdfLaTeX | 直接输出 PDF 的编译方式 |
| 宏包 | 一系列命令的合集，用 `\usepackage{}` 加载 |

---

## 写在最后

LaTeX 的学习曲线其实很短——你只需要记住：**一份文档 = 文档类 + 导言区 + document 环境**。剩下的公式、图片、表格，都是在这个骨架上不断添砖加瓦。

碰到报错不要慌，把错误信息复制去搜索，多半是少了个 `\end` 或者宏包没加载。写完第一篇文档之后，你会发现它比 Word 更省心——因为格式永远不乱。

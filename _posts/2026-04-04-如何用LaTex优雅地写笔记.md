# 用 LaTeX 写笔记

写笔记，我看重的不只是好看，更是"能长期保存、随时翻看"。LaTeX 恰好满足这一点：公式工整、结构清晰、导出 PDF 质量高。这篇用最简单的方式带你上手，零基础也能直接复制使用。

## 一、快速入门模板（直接复制可用）

你只需要记住：**LaTeX = 结构 + 内容**，不用管样式，专注写内容。

```latex
\documentclass{article}
\usepackage{ctex}       % 支持中文
\usepackage{amsmath}    % 数学公式
\usepackage{amssymb}    % 数学符号
\usepackage{geometry}   % 页面设置
\geometry{a4paper, margin=1in}

\title{我的优雅 LaTeX 笔记}
\author{Duckweed}
\date{\today}

\begin{document}
\maketitle
\tableofcontents
\newpage

\section{基础知识点}
这是一段普通文字。LaTeX 会自动处理换行、分段、间距。

\subsection{子章节}
笔记可以无限分层，结构非常清晰。

\section{数学公式}
% 行内公式
质能方程 $E=mc^2$ 是现代物理的基础。

% 独立公式
\[
\nabla \cdot \vec{E} = \frac{\rho}{\varepsilon_0}
\]

% 多行公式
\begin{align*}
F &= ma \\
\oint_L \vec{A} \cdot d\vec{l} &= \iint_S (\nabla \times \vec{A}) \cdot d\vec{S}
\end{align*}

\section{列表与重点}
\begin{itemize}
    \item 重点内容 1
    \item 重点内容 2
    \item 重点内容 3
\end{itemize}

\end{document}
```

## 二、写笔记最常用的 5 个功能

### 1. 章节结构
```latex
\section{一级标题}
\subsection{二级标题}
\subsubsection{三级标题}
```

### 2. 数学公式（最常用）
```latex
% 行内公式
$a^2 + b^2 = c^2$

% 独立公式
\[
\int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}
\]

% 多行公式
\begin{align*}
y &= ax + b \\
f'(x) &= \lim_{\Delta x \to 0} \frac{f(x+\Delta x)-f(x)}{\Delta x}
\end{align*}
```

### 3. 列表（整理笔记神器）
```latex
% 无序列表
\begin{itemize}
    \item 知识点 A
    \item 知识点 B
\end{itemize}

% 有序列表
\begin{enumerate}
    \item 第一步
    \item 第二步
\end{enumerate}
```

### 4. 重点标注
```latex
\textbf{加粗重点}

\textit{斜体强调}
```

### 5. 插入代码（计算机类笔记）
```latex
\usepackage{listings}
\begin{lstlisting}[language=C]
int main() {
    printf("Hello LaTeX");
    return 0;
}
\end{lstlisting}
```

## 三、最适合学生的笔记工作流

3. 上课直接敲知识点 + 公式
4. 自动生成干净 PDF
5. 期末直接变成复习资料

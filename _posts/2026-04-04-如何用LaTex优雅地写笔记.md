# 如何用 LaTeX 优雅地写笔记
## 前言
在大学学习、科研、刷题的过程中，一份**整洁、规范、可长期保存**的笔记，远比杂乱无章的手写稿更有价值。
LaTeX 不是复杂的排版工具，而是能让你**专注内容、自动排版、公式优美**的笔记神器。用它写笔记，结构清晰、公式优雅、导出 PDF 质量极高，长期坚持会形成极强的学术习惯与效率优势。

这篇博客，我用最简单、最实用的方式，教你**如何用 LaTeX 优雅写笔记**，零基础也能快速上手。

---

## 一、为什么推荐用 LaTeX 写笔记？
1. **公式极美**：数学、物理、电子、计算机公式自动渲染，比任何编辑器都干净
2. **结构自动管理**：章节、目录、标题、列表、引用一键生成
3. **格式永远不乱**：不像 Word 动不动排版崩溃
4. **纯文本可版本管理**：配合 Git 永久保存、随时回溯
5. **学术气质拉满**：写作业、报告、笔记、论文一套工具通吃

## 二、5 分钟快速入门（直接复制可用）
你只需要记住：**LaTeX = 结构 + 内容**，不用管样式，专注写内容就行。

### 最简笔记模板
```latex
\documentclass{article}
\usepackage{ctex}       % 支持中文
\usepackage{amsmath}    % 数学公式
\usepackage{amssymb}    % 数学符号
\usepackage{geometry}   % 页面设置
\geometry{a4paper, margin=1in}

\title{我的优雅 LaTeX 笔记}
\author{Duckweed}
\date{\today}

\begin{document}
\maketitle
\tableofcontents
\newpage

\section{基础知识点}
这是一段普通文字。LaTeX 会自动处理换行、分段、间距。

\subsection{子章节}
笔记可以无限分层，结构非常清晰。

\section{数学公式}
% 行内公式
质能方程 $E=mc^2$ 是现代物理的基础。

% 独立公式
\[
\nabla \cdot \vec{E} = \frac{\rho}{\varepsilon_0}
\]

% 多行公式
\begin{align*}
F &= ma \\
\oint_L \vec{A} \cdot d\vec{l} &= \iint_S (\nabla \times \vec{A}) \cdot d\vec{S}
\end{align*}

\section{列表与重点}
\begin{itemize}
    \item 重点内容 1
    \item 重点内容 2
    \item 重点内容 3
\end{itemize}

\end{document}
```

## 三、写笔记最常用的 5 个功能
### 1. 章节结构
```latex
\section{一级标题}
\subsection{二级标题}
\subsubsection{三级标题}
```

### 2. 数学公式（最常用）
```latex
% 行内公式
$a^2 + b^2 = c^2$

% 独立公式
\[
\int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}
\]

% 多行公式
\begin{align*}
y &= ax + b \\
f'(x) &= \lim_{\Delta x \to 0} \frac{f(x+\Delta x)-f(x)}{\Delta x}
\end{align*}
```

### 3. 列表（整理笔记神器）
```latex
% 无序列表
\begin{itemize}
    \item 知识点 A
    \item 知识点 B
\end{itemize}

% 有序列表
\begin{enumerate}
    \item 第一步
    \item 第二步
\end{enumerate}
```

### 4. 重点标注
```latex
\textbf{加粗重点}

\textit{斜体强调}
```

### 5. 插入代码（计算机类笔记）
```latex
\usepackage{listings}
\begin{lstlisting}[language=C]
int main() {
    printf("Hello LaTeX");
    return 0;
}
\end{lstlisting}
```

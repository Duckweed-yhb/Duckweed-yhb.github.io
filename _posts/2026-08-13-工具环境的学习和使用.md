# 工具环境

大学里有一类能力，课堂不教，却比某一门课更影响你的四年效率——工具环境的搭建和使用能力。这篇整理我常用的几套工具配置要点，供你参考。

## 一、VS Code：一个编辑器搞定所有语言

下载地址：[code.visualstudio.com](https://code.visualstudio.com/)

安装后的基础设置：
1. **设置自动保存**：File → Auto Save（勾选）
2. **安装中文语言包**：扩展商店搜索 "Chinese (Simplified)"
3. **配置字体**：`Settings → Font Family → 'Cascadia Code', 'Sarasa Mono SC', 'Fira Code'`

### Profile：一键切换开发环境

| Profile 名称 | 安装的插件 | 使用场景 |
|-------------|-----------|---------|
| LaTeX写作 | LaTeX Workshop + LTeX + PDF Viewer | 课程笔记、实验报告、论文 |
| Python开发 | Python + Pylance + Jupyter | 数据处理、科学计算 |
| Java开发 | Java Extension Pack + Spring Boot | 课程设计、后端项目 |
| 前端开发 | ESLint + Prettier + Vue/React | 博客维护、Web项目 |

创建方法：左下角齿轮 → Profiles → Create Profile → 选择 "Empty Profile" → 只安装当前场景需要的插件。切换 Profile 时，其他环境的插件完全不会加载。完整教程见（👉 [VS Code 配置管理](/2026/03/30/VScode插件管理/)），插件清单见（👉 [VS Code 插件推荐](/2026/03/30/VScode插件推荐/)）。

## 二、Git/GitHub：代码的时光机

**Q：Git 和 GitHub 有什么区别？**
Git 是版本控制工具（装在你电脑上），GitHub 是代码托管平台（在云端）。

**Q：不用 Git，用 U 盘/网盘备份行不行？**
不行。Git 给你的是**版本历史**——可以随时回到三天前、三周前甚至三个月前的任何一个版本，"最终版.docx"做不到。

**Q：怎么学？**
用 `git init` 初始化一个测试仓库（不要在重要项目里试），把下面 5 条命令每条敲 10 遍：

```bash
git init                          # 在当前文件夹初始化Git仓库
git status                        # 查看当前状态（最常用，没事就敲一下）
git add .                         # 暂存所有改动
git commit -m "描述你做了什么"      # 提交一个版本快照
git log --oneline                 # 查看提交历史
```

然后注册 GitHub 账号，创建远程仓库，把本地仓库推上去。详细步骤见（👉 [清理 Git 历史](/2026/07/16/GitHub仓库清理历史记录/)）。

## 三、LaTeX：告别排版地狱

- 写实验报告：Word 表格和公式随时崩，LaTeX 一劳永逸
- 课程笔记：公式优雅，目录自动生成
- 毕业论文：哈工大等高校提供 LaTeX 毕业论文模板

### 环境搭建

**方案一：Overleaf（在线，零配置，推荐入门）**
- 网址：[overleaf.com](https://www.overleaf.com)，注册即用
- 缺点：免费版有编译时长限制，需要网络

**方案二：本地环境（进阶）**
- Windows：安装 MiKTeX 或 TeX Live + VS Code + LaTeX Workshop 插件
- 入门教程见（👉 [用 LaTeX 写笔记](/2026/04/04/如何用LaTex优雅地写笔记/)），模板见（👉 [LaTeX 模板分享](/2026/03/16/latex-template/)）

### 新手最简工作流

1. 打开 Overleaf
2. 复制一份模板
3. 只改 `\section{}` 和正文，不要碰样式代码
4. 点「Recompile」看效果
5. 导出 PDF

## 四、终端/Terminal：工程师的通用控制面板

终端的本质很简单：**用文字指令替代鼠标点击**。Git 核心操作、Python 环境管理、批量操作文件、SSH 远程连接都离不开它。

工科生必会的 10 条终端命令：

```bash
ls          # 列出当前目录的所有文件
pwd         # 显示当前所在目录的路径
cd 文件夹名   # 进入某个文件夹
cd ..       # 返回上一级目录
mkdir 名字   # 新建文件夹
code .      # 用VS Code打开当前目录（需先安装VS Code的Path）
python 文件名.py    # 运行Python脚本
pip install 包名    # 安装Python包
clear       # 清空屏幕
上下箭头       # 浏览之前的命令历史
```

## 五、MATLAB：电气工程的仿真利器

### 入门路径

1. **矩阵运算**：MATLAB = MATrix LABoratory，一切都是矩阵
   ```matlab
   A = [1 2; 3 4];     % 定义一个2×2矩阵
   b = [5; 6];          % 列向量
   x = A\b;             % 解线性方程组 Ax=b
   ```
2. **函数与脚本**：把重复计算写成 `.m` 文件
3. **绘图**：`plot(x, y)`、`subplot`、论文级图表参数
4. **Simulink**：拖拽模块搭建系统仿真（电力电子、控制系统建模）

### 经典应用场景

| 场景 | MATLAB能做什么 |
|------|---------------|
| 电路分析 | 矩阵法解节点电压方程 |
| 电力系统 | 牛顿-拉夫逊法潮流计算 |
| 信号处理 | FFT频谱分析、滤波设计 |
| 实验报告 | 数据拟合、误差分析、精美图表 |
| 自动控制 | Bode图、根轨迹、PID参数整定 |

## 六、工具学习的通用方法

1. **不要看完整教程，先跑通一个最小闭环**：Git 完成一次 `init → add → commit`；LaTeX 复制模板改标题编译导出；Python 跑通第一行 `print("Hello World")`。
2. **遇到问题，优先查官方文档**：CSDN 的教程可能是过时信息，官方文档永远最新。
3. **把配置标准化**：花一个晚上搭好环境，后面四年受益。
4. **用博客记录工具配置**：换设备时能快速复现，也能帮到其他同学。

## 写在最后

工具是用来放大生产力的。一个会熟练使用 Git 的 C 语言入门者，比不会 Git 的 C 语言熟手更高效——因为前者可以无所顾忌地尝试和回滚。

大一结束前，请确保掌握：**VS Code + Git + 终端 + 至少一门语言的完整开发环境**。

私有仓库转公开时，有个容易被忽略的风险：历史提交里的旧文件仍然可见。这篇记录如何清除全部提交历史、只保留当前版本。

### 核心结论
私有仓库切换为公开仓库，**仅仅修改访问权限，不会删除任何 Git 历史**。所有人仍可查看：
- 全部提交记录
- 所有历史版本文件
- 曾经上传、后续又删除的内容

> 即使你在新版本中删除了密钥、证件等隐私文件，旧提交快照依然永久保留，一旦公开就会泄露。

### 需求场景
只想公开最新代码，**清除所有过往提交历史**，仅保留当前文件。GitHub Desktop 没有对应图形按钮，配合内置终端即可完成。

### 前置操作（必做）
1. 完整备份仓库（下载归档或复制本地文件夹）
2. 确保本地没有未提交的改动
3. 网页端临时关闭 main 分支保护规则，否则强制推送会失败

### 操作步骤
1. GitHub Desktop 选中目标仓库，切换到主分支（main）
2. 顶部菜单 `Repository → Open in Terminal`
3. 依次执行命令

```bash
# 创建无历史孤儿分支
git checkout --orphan new-clean
# 暂存当前所有文件
git add .
# 创建全新初始提交
git commit -m "Initial commit (clean history)"
# 删除旧主分支
git branch -D main
# 重命名分支为主分支
git branch -m main
```

整个过程不可逆，动手前请务必先备份。

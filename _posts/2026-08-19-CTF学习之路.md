# CTF 学习之路

## 前言

CTF（Capture The Flag，夺旗赛）是网络安全领域最流行的竞赛形式——选手通过挖掘题目中的漏洞，找到隐藏的 flag 字符串来得分。

如果你想系统入门网络安全，CTF 是最好的切入方式：它把庞大的安全知识拆解成一道道具体的题目，让你在"解题"中自然掌握技能。这篇整理一条 CTF 学习路线，以及几个最值得用的平台。

---

## 一、CTF 的五个方向

| 方向 | 中文 | 核心内容 | 入门难度 |
|------|------|---------|---------|
| Web | Web 安全 | SQL 注入、XSS、文件上传、命令执行 | ⭐ 相对友好 |
| Misc | 杂项 | 隐写、取证、编码、流量分析 | ⭐ 相对友好 |
| Crypto | 密码学 | 古典密码、现代密码、数学基础 | ⭐⭐ |
| Reverse | 逆向工程 | 反汇编、调试、算法逆向 | ⭐⭐⭐ |
| Pwn | 二进制漏洞利用 | 栈溢出、堆利用、ROP | ⭐⭐⭐⭐ |

新手一般建议从 **Web** 或 **Misc** 入手，这两个方向门槛相对低、反馈快，容易建立成就感。

---

## 二、学习路线

```
了解 CTF → 选定方向 → 打基础 → 刷题 → 参赛实战
```

### 第一步：了解 CTF 是什么

先搞清楚 CTF 的规则、方向、常见题型，推荐从 **Hello CTF** 开始：

- 网站：[hello-ctf.com](https://hello-ctf.com/)

这是一个面向新手的 CTF 入门指南，讲清楚 CTF 是什么、怎么学、怎么打比赛，适合作为第一站。

### 第二步：系统查知识

刷题遇到不会的，随时查 **CTF Wiki**：

- 网站：[ctf-wiki.org](https://ctf-wiki.org/)

目前最全的中文 CTF 知识库，按方向系统整理了 Web、Pwn、Reverse、Crypto、Misc 等各方向的核心知识点和技巧。它是你的"字典"，不用背，但要会用。

### 第三步：大量刷题

知识要在题目里才学得会。推荐 **CTFHub**：

- 网站：[ctfhub.com](https://www.ctfhub.com/)

CTF 在线学习实训平台，提供完善的题目环境和配套 writeup（题解），按技能树分专题闯关（SQL 注入、文件上传等）。**开箱即用**，不用自己搭环境，非常适合入门练习。

### 第四步：接触大赛真题

基础扎实后，去 **攻防世界** 挑战真题：

- 网站：[adworld.xctf.org.cn](https://adworld.xctf.org.cn/)

XCTF 国际联赛官方练习平台，收录国内外大赛真题，题目覆盖 Web、Pwn、Crypto、Misc 等全类型，并提供**新手区 → 进阶区 → 高手区**的梯度训练。想感受真实比赛难度，就来这里。

---

## 三、几点建议

1. **别贪多**：先专注一个方向（建议 Web 或 Misc），把一个方向学深，比五个方向都浅尝辄止强得多。

2. **看 writeup 不丢人**：卡住了就去看题解，关键是想明白"为什么这样做"，而不是抄答案。

3. **善用搜索**：CTF 的很多技巧在搜索引擎里都能找到，学会用准确的英文关键词检索。

4. **找同伴**：加入学校的 CTF 战队或线上交流群，一起打比赛、互相讲题，进步会快很多。

---

## 写在最后

CTF 的魅力在于：它把"学安全"变成了一场解谜游戏。你不需要一开始就精通一切，只需要从第一道题开始，一步步走下去。

祝你在夺旗的路上，越走越远。

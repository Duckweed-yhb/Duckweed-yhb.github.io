# 推荐一个 CS 自学社区

最近逛到一个很对胃口的站点：[CS 自学社区](https://www.learncs.site/)。它把美国顶尖大学的计算机核心课程串成一条可执行的学习路线，所有资源免费获取，还配套中文翻译，正好补上我一直念叨的"计算机核心基础"。这篇把它的理念和路线图整理出来，方便自己查阅，也分享给需要的人。

## 一、社区在做什么

社区由一位**非科班出身、自学编程转行后端开发（8 年+ 工作经验）**的程序员创建。他的核心主张很直接：**计算机学科的核心基础，比"会写代码"重要得多**——所以他给社区起名叫"CS 自学社区"，而不是"编程自学社区"。

社区的目标是：

- 精选美国顶尖大学最负盛名的计算机核心课程，整理成一份课程清单——掌握这些课程，**能达到一流大学 CS 专业本科毕业水平**
- 组织学习计划、跟踪学习进度，把自学的同学聚集在一起，避免独自硬啃时的孤独和无助
- 用两到三年时间打下坚实的计算机基础，掌握后端技术栈，之后可以轻松拓展到人工智能、大数据、图形学等方向

## 二、第一门编程语言怎么选

这是每个新手最纠结的问题，社区的观点很清醒：

- **不存在"最佳"的起步语言**，第一门语言也几乎不会决定你未来的职业走向
- 编程语言表面差异很大，但**绝大多数基本概念都能在不同语言之间迁移**
- 新手熟悉第一门语言可能要数月，有经验的程序员学一门新语言只需数天
- 优秀程序员的标志之一，是掌握多种类型语言后，能为手头的任务选合适的工具

所以别在"先学 Python 还是先学 C"上内耗太久——**概念才是重点，先跑起来**。

## 三、社区提供什么

| 支持 | 说明 |
|------|------|
| 免费课程资源 | 路线图中所有课程均可在网上免费获取 |
| 中文翻译 | 英文教材逐个翻译，视频有精确翻译字幕，部分课程有中文配音 |
| 配套资料 | 阅读资料、作业、实验等一并整理 |
| 学习支持 | 制定学习计划、跟踪进度、答疑 |
| 交流群 | 官方创建的学习交流群，加群入口在社区版块 |

社区运营靠赞助维持，学习资源本身**全部免费**。它的原话是："你不能购买成功"——按自己的时间和预算决定投入多少即可。

## 四、路线图概览

路线图分两大部分：**核心基础课程**（CS50、CS61 系列 + 数学课程）和**高级系统与原理课程**（计算机网络、编译原理、操作系统、分布式系统、数据库系统）。

| 模块 | 课程 | 要点 |
|------|------|------|
| 编程入门 | Harvard CS50x | 面向所有人的导论课，涵盖算法、数据结构、软件工程与网络，涉及 C / Python / JavaScript / SQL，资源极全，适合第一课 |
| 编程入门 | UC Berkeley CS61A | 沿袭 SICP 精神、以 Python 讲解程序的构造与解释，培养编程与解决问题的能力 |
| 算法与数据结构 | UC Berkeley CS61B | 数据结构与算法，重点在于应用与对 Java 实现的科学性能分析 |
| 计算机系统结构 | UC Berkeley CS61C | C 语言与 RISC-V 汇编，深入数字电路、CPU、Cache、虚拟内存与并行计算 |
| 数学基础 | MIT 18.01 / 18.02 | 单变量、多变量微积分 |
| 数学基础 | MIT 18.06 | 线性代数 |
| 数学基础 | MIT 6.042J | 离散数学：图论、状态机、模运算、计数与离散概率 |
| 操作系统 | UC Berkeley CS162 | 进程与并发、内存分配、文件系统、网络与分布式、安全 |
| 计算机网络 | Stanford CS144 | 分组交换与分层协议，动手实现路由器和数据传输服务 |
| 数据库系统 | CMU 15-445 | 数据库内核：存储、索引、并发控制，项目驱动 |

社区给出的学习顺序建议是：**CS50x → CS61A → CS61B → CS61C → 数学 → 系统课程**。其中特意强调：先学 CS50x 再上 CS61A，避免难度跳跃过大、挫伤信心。

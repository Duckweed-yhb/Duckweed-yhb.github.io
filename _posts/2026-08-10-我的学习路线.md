# 我的学习路线

常有学弟学妹问我"大学到底学了哪些东西"。回头看，两年多的学习轨迹不是一条直线，而是一张逐渐扩展的网。这篇梳理我从大一到现在的学习路线——不是"你应该怎么学"，而是"我是怎么学的"，仅供参考，切勿照搬。

## 一、大一（2024.09 — 2025.07）：通识打底 + 编程启蒙

**数学**：高等数学（极限 → 微分 → 积分 → 级数 → 微分方程）是后续所有工科课的数学语言；线性代数当时觉得抽象，后来学电磁场和潮流计算才意识到矩阵无处不在。

**编程**：大一下正式开始——C 语言是必修课但课堂节奏太快，真正学懂在课后，用一个寒假把 8 章从头敲了一遍（就是博客里那篇 8 章笔记的由来）；第一次接触 Git 只是为了交作业不丢代码，用 `git init` + `git commit` + `git push` 三步流，后来成了最核心的工具之一。

大一结束时，数学基础够用，C 语言能独立写 200 行以内的程序，Git 基本操作熟练。最大的体会：**课堂上学的永远只是引子，真正的消化发生在课后**。

## 二、大二上（2025.09 — 2026.01）：专业课启动 + 工具链建设

**专业基础课**：电路分析是电气大厦的地基，建议配合 Multisim 做仿真；模拟电子技术难度骤升，跟着 B 站郑益慧的视频过了两遍才建立直觉；数字电子技术相对友好，逻辑门 → 组合电路 → 时序电路思路清晰。

**工具链建设**：VS Code 配置了 LaTeX + Python + Java 三套 Profile；开始用 LaTeX 整理课堂笔记，第一份完整产出是大学物理笔记；第一次用 MATLAB 解电路节点方程组。

这学期最大的成长不是某门课，而是**学会"学工具"**——Profile 隔离、LaTeX 模板复用、MATLAB 矩阵计算，这些能力后来反复用到。

## 三、大二下（2026.02 — 2026.07）：专业深入 + 博客搭建

**专业核心课**：电磁场与电磁波是最硬的理论课，我用 LaTeX 整理了完整笔记（博客里有 PDF）；概率论与数理统计是数学建模课的预修，同样整理了笔记；信号与系统为自动控制原理打基础。

**博客搭建**：2026 年 2 月用 Jekyll + GitHub Pages 搭了个人博客，初衷很简单——笔记散在本地文件夹，换个设备就找不到，放到博客上随时可查、还能分享。踩过的坑包括 Jekyll 中文路径编码、Liquid 模板与 Markdown 解析冲突、GitHub Actions 部署配置（另见 👉 [GitHub仓库清理历史记录](/2026/07/16/GitHub仓库清理历史记录/)）。

大二结束时，电气工程专业骨架搭建完成，编程能力从 C 扩展到 Python 和 Java 基础，博客成了知识沉淀的载体。最深的感受：**整理笔记和写博客，本身就是最高效的学习方法**。

## 四、大三上（2026.09 — 至今）：深耕 + 输出

（以下为规划中/进行中）
- 电力系统分析：目标是用 MATLAB 独立实现一次完整的潮流计算
- 继电保护原理：配合实际保护装置说明书理解整定逻辑
- 准备考研：数学一 + 英语一 + 政治 + 电力系统专业课
- 博客持续输出：电气自学路线、计算机自学路线等系列文章

## 六、几条真心话

1. 不要追求"全面"：时间有限，贪多嚼不烂。我的策略是电气工程为主干、编程为辅助、博客为输出平台。
2. 工具要趁早学：LaTeX、Git、VS Code、MATLAB 大一开始接触，成本一次性、收益终身。
3. 输出是最好的输入：写完 8 章 C 语言笔记后，我对指针的理解上了一个台阶——把知识写清楚的过程会暴露自己的模糊地带。
4. 不要和别人比进度：有人大二发论文，有人大三才学 C 语言，找到自己的节奏比追赶别人更重要。

> 这不是终点，只是阶段性小结。等大三结束、考研结束、毕业前，我都会回来更新这篇"学习路线"。

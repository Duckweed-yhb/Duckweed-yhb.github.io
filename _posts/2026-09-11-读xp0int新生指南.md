# 读 xp0int 新生指南：入坑安全第一步

## 前言

[xp0int](https://www.xp0int.top/) 是暨南大学的 CTF 战队，他们面向新生写了一份 twig 般走心的《新生请看这里》——不谈高深的漏洞利用，而是把**大一到大四踩过的"计算机地狱"地图**摊开给你看。

> 波比是十八层地狱之安全方向的引路人。无论你是怀抱着对成为 hαcker 的憧憬，还是觉得计算机有前景，或者是随便选了这个专业，计算机从来都不是一个简单的学科——这是所有人共同的起点。

我循着这份指南完整读了一遍（番外篇的单方面友站：[0xffff](https://0xffff.one/)），把它的知识体系梳理如下，并把关键的操作细节重新整理为表格。原文全部观点与细节归 xp0int 战队，本站仅作条理化记录与补充。

## 一、给大一新生：先做"基本素养"

+ 计算机自学网站中的 [CS 自学指南](https://csdiy.wiki/) 请先收藏；
+ **相信你的自学能力**：它远远大于老师的讲课速度，请坚持自学，别等待；
+ 这篇文章很长，学会读长文，也算计算机必修课。

### 1.1 怎么选择编程语言？

只要一门语言是**图灵完备**的，那它几乎能让计算机做任何事。那为什么世界上还有这么多编程语言？正如不同的人类语言在不同情景有不同表达效果，不同语言在不同应用环境下功效不同：

| 类型 | 性能 | 编写难度 | 适合场景 |
|------|------|----------|----------|
| 编译型 | 快 | 高（且要忍漫长编译） | 高性能要求 |
| 解释型 | 一般 | 低 | 快速开发 |

**入门推荐 C + Python**：

- **C**：编译型祖宗级语言，许多语言的设计都受它影响。就算以后不写它，学习它有助于理解并快速学会其它语言——何况它是必修课；
- **Python**：最流行的解释型语言，易写 + 库多，小任务实现飞起。

学好一两门语言后再选择主力方向：如 Web 方向 → 前端三件套 + Java/Go/Python/PHP 等。

### 1.2 如何练习？

**第一步**：教材/书的练习题（挑着做）。掌握基本语法后有两条路（不冲突，可同走）：

1. **数据结构 + 算法**：教材 + 力扣。注意别买《算法导论》入门，它更偏向工具书。C/Python 建议刷力扣，基础升得快；Web 开发就没必要刷太狠；
2. **小项目**：找大家普遍推荐的练习向项目，也可以做自己感兴趣的小工具/小网站。**独立完成一个小项目，对整体编程能力提升显著**。

### 1.3 IDE 怎么选？

| IDE | 适用语言 | 一句话点评 |
|-----|---------|-----------|
| **Visual Studio** | C/C++/C# | 宇宙第一 IDE，高集成免配置，但体量巨大、以项目管理代码，小项目不必 |
| **VScode** | Everything | 本质是"记事本 plus"，靠插件变成任何语言的 IDE |
| **PyCharm** | Python | 公认 Python 最佳（博主没用过） |
| **PhpStorm** | PHP | PHP 代码分析利器，方便切换 PHP 版本调试 |
| **IDEA** | Java | Java 审计与开发首选，一键生成 springboot/maven，可反编译 jar/war，吃内存 |

**VS 注意事项**（新手踩坑重灾区）：

1. `.sln` 和项目文件夹不是你的源代码！真正的源码是 `.c/.cpp/.h/.hpp` 文件——别被要求发源代码时丢个 `.sln` 文件过去；
2. VS 默认无 C 语言支持，想写 C 请把 `.cpp` 后缀改成 `.c`，避免奇怪错误；
3. 小体量代码（三四文件）建议 lighter 的 IDE，VS 面向中型/大型项目。

**VScode 建议**：装简体中文包 + Code Runner（一键过编译跑 C/C++）+ Remote Development（虚拟机远程开发套件）；Windows 下 C/C++ 编译器推荐 mingw；`代码量小时`不必建项目，直接编辑文件即可。

**IDEA 有社区版**（基本够用）；真要付费，学生邮可申请一年（到期网上有其他交接护法）。

## 二、遇到问题怎么办？

> **RTFM & STFW**：Read the fxxking manual. Search the fxxking web.

初学者每天十几个问题不重样常见。问题在于：**靠别人不如靠自己**（毕竟大家都忙）。四个方法：

### 2.1 学会阅读错误提示

一大部分问题来自各种报错，报错信息里往往**藏有解决问题的方式**。英文好请务必细读；英文不好喂给翻译工具。仔细读，然后尝试照它解决。

### 2.2 学会使用搜索引擎

最直接的就是**复制粘贴报错提示**去搜。使用技巧：

- 别整句搜，提炼几个关键词更容易出结果；
- 学习基本搜索语法（参考 CS自学指南的《信息检索》一节）；
- 先百度，结果不好换谷歌（用英文搜，结果更佳——校园网能上谷歌）；
- 2023 年之后：AI 对话工具是"超级文档 + 交互式搜索引擎"，写示例、讲库函数、搭框架都很好用。**但绝不依赖它写作业，该练的一定要练**。

### 2.3 学会翻阅文档

想看"这个东西怎么用"时，若你会频繁使用它，请直接读官方文档，而不是一遍遍翻搜索引擎。

### 2.4 学会正确提问

提问前应已做过初步努力（搜过、试过几个方案）。清风正气的提问包含：

1. 描述清楚问题（用了什么、做了什么操作、出现什么报错），别丢一张图就完事；
2. 说明环境（win10 / mac / Linux…）；
3. 说明你试过什么、结果如何。

论坛就推荐**StackOverflow**。想读通透一点，请看《[提问的智慧](https://github.com/tvvocold/How-To-Ask-Questions-The-Smart-Way)》中文版。

## 三、做好磁盘管理

两条老生常谈但常劝不住：

1. **别全部默认路径安装**，全 C 盘上爆是迟早的事；
2. **分门别类**存文件，学计算机后面工具只会越来越乱。

顺便：多买一个大容量移动硬盘做备份，迟早用得上。

## 五、习惯"黑框框"（终端）

多数程序没有 GUI，得了终端恐惧症走不远——尤其是 Linux 与终端高度捆绑。

**Windows**：微软商店装 **Windows Terminal**（多终端集成器 + 字体/背景/外观自定义），再进阶可用 **oh-my-posh** 选主题。

**Linux**：换成 **zsh + oh-my-zsh**（命令高亮、提示、补全远强于 bash）。参考 `oh-my-zsh Ubuntu` 搜索教程。

**Mac**：同样可用 oh-my-posh / oh-my-zsh。

## 六、环境变量？

简单说就是系统级"全局变量"，告诉软件系统信息。最常用的是 `Path`：把程序的**父文件夹**路径放进 `Path`，终端直接输程序名即可调用。

配置位置：右键"此电脑" → 高级系统设置 → 环境变量。

> ⚠️ **非必要不要手动改环境变量**！Java 版本冲突等玄学问题多出于此。

## 七、家中常备 Linux

生态问题决定了：**做安全 100% 要跟 Linux 打交道**（开源工具生态、服务器系统、IoT……）。而且 Linux 相对 Windows 更透明，学前基础更舒服。

### 7.1 发行版怎么选

| 发行版 | 定位 | 推荐用法 |
|--------|------|---------|
| **Ubuntu** | 最流行个人发行版，各方面平均最稳定 | VMware 或 WSL2；官网拿桌面版 iso，WSL2 在微软商店 |
| **Kali** | 基于 Debian 的渗透测试专用发行版 | 集成几百款安全工具，带 GUI 更好用，建议 VMware 官网[下载虚拟机版](https://www.kali.org/get-kali/#kali-virtual-machines)直接导入 |

### 7.2 Linux 运行在哪？

| 方案 | 优点 | 缺点 |
|------|------|------|
| **VMware** | 完整 GUI、丰富配置、快照管理（pro） | 体量大、易卡、占空间多 |
| **WSL2** | 启动完爆 VMware、小巧自动扩容、与微软生态深度契合（VScode 支持好） | 没桌面版（可跑 GUI 程序）、魔改内核偶有小问题、快照不如 VMware |
| Docker / docker-compose | 封装独立环境容器，与主机互不影响 | 用于 CTF 自搭题目环境；建议 Ubuntu 下安装，compose 用 v2 |

**VMware 注意**：虚拟磁盘**只能调大不能调小**；装好自带的 vmtools 可直接拖拽传文件；不用时休眠或关机。

**WSL2 步骤**（走跳过 C 盘的路径）：

```powershell
wsl --set-default-version 2
wsl --install
wsl --update
# 重启后微软商店装 "Ubuntu"（稳定版）——默认装 C 盘，需手动移到别的盘：
# 在 C:\Program Files\WindowsApps\ 找 CanonocalGroupLimited* 文件夹
# 把 ubuntu.exe 及其所有内容复制到目标盘符文件夹，双击运行即可
```

密码输入不回显不是 bug，正常连打两遍即可。之后在 Windows Terminal 中出现 wsl 选项卡，文件管理器还能直接挂虚拟机文件系统、像普通文件夹那样传文件。

### 7.3 初步使用 Linux

**常用命令**：

```bash
cd / ls / cat            # 进入 / 列出 / 查看内容
mv xxx yyy               # 移动
cp xxx yyy               # 复制
sudo xxx                 # 以 root 权限执行
xxx | yyy                # 管道：xxx 输出作为 yyy 输入
echo "xxx" | base64 -d   # 解码 base64
... > xxx.txt            # 输出重定向到文件
xxx --help               # 查看帮助（非常有用）
```

**包管理**：Linux 亮点。Ubuntu 用 `apt`：

```bash
apt install xxx     # 安装包
apt help            # 帮助
```

默认源下载慢，请换源：搜 `Ubuntu 换源`。语言包管理器同理（国内镜像一搜一大把）。

## 八、大二：地狱三选一

大一没学也没事，把大一该做的补上，勤快点就赶得回来。大二最重要的任务：**确定方向**。

### 8.1 开发？竞赛？科研？

| 路径 | 特点 | 建议 |
|------|------|------|
| **开发** | 码农/业务开发 + 大创、挑战杯、互联网+ 等项目向比赛 | **属后路**：可先尝试其他再选，且与学生任一路并行 |
| **竞赛** | CTF / ACM，问就是刺激、高手云集 | **周期短**：能较快知道自己适不适合，可优先尝试 |
| **科研** | 跟老师打杂、拼论文 | **看导师**：出成果很慢，谨慎选择老师与课题 |

### 8.2 研究方向

大方向：安全 / AI / 业务开发 / 算法。选了网安不等于只能做网安，但与业务开发的距离会拉开。小方向：系统安全、密码学、二进制、Web、区块链……每个差别巨大，**隔行如隔山**，多和老师/学长学姐聊。

## 九、初入安全（or CTF）

> ⚠️ 前置：**熟悉一门语言** + **已有 Linux 环境**。

安全知识浩如烟海分支众多，还与计算机、数学基础深度耦合（密码学要数学，二进制要操作系统与编译原理），学习曲线非常陡峭。等学校教？学完 4 年可能啥也不会。

**解药：CTF（Capture The Flag）**——起源于 1996 年 DEFCON 全球黑客大会（代替以真实攻击比拼的旧方式）。CTF 几乎囊括网安所有领域，以社区驱动为主，近几年的萌新赛题与练习平台已经相当完善——**数学有配套练习题，CTF 也有**。

它的价值不是成绩，而是：

- **实操能力**：网安最看重动手，学校很难补上这一课；
- **理论结合实践**：密码学题目加深对算法的理解，二进制题目加深对计算机底层的理解；
- **接触前沿**：甚至会被逼着看论文，学术水平顺带提升。

怎么入门？直接跟手册：**[Hello CTF](https://hello-ctf.com/)**。

学习要领：**多做练习、多总结、多看别人怎么做**。一般一个人**主攻一个方向**就很极限了，切勿雨露均沾——先都尝尝门酒，看自己对哪有兴趣、哪有能力，再沿一条路深耕。

正文两本推荐书：

- 纯小白：安恒《CTF实战：从入门到提升》
- 有一定基础：Nu1L《从0到1：CTFer的成长之路》

一句告诫：**不要为了刷题而刷题**，打 CTF 是手段，体会题目背后考察的知识点、补上自己基础短板才是目的。

## 十一、写在这里后的：给自己一个学习理由

原文最后一段值得单独拎出：

> 大一的主要任务不是 API 文档 xxx 安全，而是先做好一个**计算机从业者**的基本素养：坚持写代码、会解决问题、环境配置到位。
>
> 更重要的，是探索**自己为什么要学习计算机**。任何方向的知识海洋都一望无际，几年翻新一次，你必须准备好不断学习。可能你努力好久仍被大哥狠狠摩擦、怀疑人生——如果找不到推动自己不断学习的动力，哪怕单纯上课也会被消磨掉激情。反之，找到解锁点后，你还会自然激发超强的自学能力！
>
> **给自己一个学习的理由**，无论是兴趣还是名利，不然还没游一半就直接溺水了。

计算机的学习看似枯燥，没有游戏的正反馈，但找对路径（CTF 就是那种做出来就开心的"正反馈"）后，它能给你远胜负它的成就感。若确有困难，也请认真思考转专业，切勿折磨自己。

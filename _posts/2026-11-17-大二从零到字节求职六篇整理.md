# 「大二从零到字节」求职六篇：学习、心态、算法、简历、项目、面试

> 来源：小红书博主 **花緑青** 的系列帖《大二从零到字节之路》，共六篇（学习方法 / 心态 / 算法 / 简历 / 项目 / 面试）。以下按篇摘录要点，措辞做了书面化整理，观点归属原博主。
>
> 适用边界：原文是**互联网后端校招 / 实习**语境，博主本人大二拿到字节 offer；里面关于项目包装、八股导向的说法只取方法论部分，项目真实性和诚信底线不在这套话术之内。对自己的用法是：取准备节奏、简历结构、刷题路径这些可复用的部分，不照搬「做没做过没人在意」的结论。

## 一、学习方法篇：目标先收敛到「通过面试」

- 博主复盘自己踩过不少坑、浪费过时间，认为**在合理规划下，达到大厂面试通过的水平并不需要那么久**。
- 从第一性原理看，目的是通过面试，除此之外的能力都是次要的；面试在短时间内探不出真实实力，所以「包装」的艺术体现在一句话：**确保简历上的每一句话都不会被问穿**。
- 这句话有两层意思：一是知识储备要足够扎实；二是只要能自圆其说，都算你的。没人在意你究竟做没做这个项目——你只需要足够了解自己的项目：会在哪些极端情况下出问题、为什么这样选型、为什么选这个技术方案，都能答上来，就算做过。
- 八股同理：没人在意你懂不懂 Java 的每个 API、SSM 的每个原理，能流畅答出问到的八股，就算精通。这也解释了为什么很多认真学了很久的同学反而通不过面试。
- 反过来问什么是有效学习：认真看完四百集黑马网课，第二天还记得多少？如果只是为了在弹幕上发「实名内卷」，值得思考。

## 二、心态篇：运气 > 心态 > 信息差 > 实力

- 博主对找工作因素的排序：**运气 > 心态 > 信息差 > 实力**。运气没法教，心态是次于运气的最大可变量。
- 语言选择上，后端大致只有 Java 和 Go 两种主流：
  - **Go**：应对高并发的原生语言，大厂标配，在高速扩张，八股量大约是 Java 的五分之一。
  - **Java**：中国岗位存量最大、百搭，但八股繁多、竞争激烈、培训规模化。
- 博主推荐先学 Java，两条理由：存量最大，约 80% 岗位还是 Java，有退路；Go 岗位接受 Java 转，Java 岗位不接受 Go 转，Go 的路太窄，除非有把握一定能进大厂。
- 不必苛责过去的自己：不会有任何一天比今天更年轻，种树最好在十年前，其次是现在。评判后悔的唯一标准是——如果重新来一遍，结局会不会有变化；答案是没有，就不必懊悔。
- 过去只是过去，复盘总结过去是为了更好的现在和未来；不用纠结每次选择是不是局部最优，要看自己是否在正确方向上前进。
- 不要盲目焦虑，就像 agent 推理会出现幻觉：无论如何先行动起来，感知真实环境，反思，再决定下一步。「学而不思则罔，思而不学则殆」。
- 计算机圈子里，越大佬往往越不吝赐教，也希望能和大家成为朋友、一起成长。

## 三、算法篇：分两条路径，配三遍刷题法

- 先建立认知：看到一道新算法题写不出来完全正常，绝大部分人（包括博主）都没有算法天赋，要找一个更适合多数人的方法。
- 按时间分两类：
  1. **不着急找工作、想打基础**：找一个完整题单（灵神），按模块进行；每个模块有一两道母题延伸，一条循序渐进做起来更舒服，一条训练举一反三、观察细微差异与本质。
  2. **马上要面对面试**：几百道题单肯定来不及，立刻上 Hot 100 和 CodeTop，面试约 70% 从中出原题；字节偶尔偏门，但攻克 Hard 性价比很低。
- **三遍刷题法**：
  - 第一遍：迅速过题，三分钟没思路就看题解；目标是建立初步印象，找到自己能理解的题解，理解并保存下来。
  - 第二遍：尽量第二天回顾前一天的题，大体建立题目框架，往里填代码，细节可以忘。
  - 第三遍：第三天能自己想起注意点，独立一次 OC 完成，这道题才算学完。
- 刷题核心在**集中大量 + 养成习惯**：把算法当成每天都要做的事，留出一上午专门做算法，一次十几道，效果比一天一两道好得多；后面越刷越熟练，Hot 100 几个小时就能过一遍。
- 核心代码就是力扣；ACM 是自己导包、自己写输入输出，链表和二叉树这类输入一般可以写死，面试前练一下就好。Java 记得写 `import java.util.*`（博主称血的教训）。
- 算法运气成分依旧很大，想都撕出来，一两百题不够，取决于面试官想不想为难你（博主备注：字节除外，纯阴间）。想让你过，算法就会出常见点。即使算法再没用，也是工作必经之路；很多先进的组开始不考算法或考 vibe coding，但短时间内仍是面试必须准备的部分。

## 四、简历篇：一张让面试官看过去舒服的纸

先自查六条，满足任何一条都需要优化：

1. 花哨、分左右栏的简历模板；
2. 社团、班委、学生会主席、各种水赛和奖学金全写上去；
3. 全屏技术词汇都加粗；
4. 标点、字号、间隔、字体不正常；
5. 写个人爱好、自我评价；
6. 没实习也写到两页以上。

简历是给面试官看的、**一眼展示你与岗位匹配度的一张纸**。优秀简历的要点：

1. 不是多段实习，压缩在一张纸。
2. 简历里每个字都是岗位需要的，任何一个字都不会被问穿；放的链接面试官会去看，没把握就不要写。
3. 包含联系方式、教育背景、实习经历、项目经历、高含金量竞赛（如 ACM）、技能，其他一概不写；自认为丰富的校园经历在职场没有用处；绩点不高不写，四六级不高不写（600+ 才写）。
4. 框架带来的接口能力不是亮点，亮点是在此基础上解决痛点的优化，而优化要有对比指标数据。
5. 如果是 985 一定要标记出来，校徽图案放左上角。
6. 选最简洁的模板，不要花里胡哨的图案，华而不实，面试官喜欢简洁。
7. 可以放照片，但要好好拍，至少别放随手拍上去，是态度问题。
8. 有精力针对不同岗位做多个简历，不一个简历通投。
9. 可以在技能里埋八股的钩子，不过效果有限。
10. 多去网上看优秀简历和垃圾简历对比。

博主说这是前后改了十几版简历得出的经验；简历是面试的主战场，任何提问都会从简历开始，写完简历就可以开始投了。

## 五、项目篇：亮点在优化，不在堆功能

**「项目」是什么？课程作业算吗？要不要做外卖和点评？**

- 项目是有完整目标、自己动手做完、能落地、能写进简历的完整作品。图书管理系统这类课程作业也算项目，但太 low、没有亮点，不能往简历上写。
- 实现框架原有能力不是亮点，做出来一个完整系统也不是亮点，**只有在此基础上的优化才是亮点**（比如 chunking 的父子切分）。可以这样想：我为了解决什么痛点？引入了什么优化？为什么不用其他方案？优化前的数据怎么样？优化后的数据怎么样？
- 项目在面试中承担考察架构设计能力、问题处理能力和八股理解能力的作用；面试基本不会单独拷打八股，而是结合你的项目场景去问。如果项目面试官不感兴趣，就要做好接受一小时八股拷打的准备。
- **不要外卖和点评**：一千份简历八百份外卖点评，怎么包装都看得出来，看见秒杀就吐了。这两个是很优秀的教学，但建议学完理解之后，换其他项目放简历里。

**我的项目是什么？从哪里找的？**

- 博主放简历的两个项目：一个多 Agent 智能体系统，一个高性能视频分享平台。
- 多 Agent 是先做了单 Agent，感觉不够用，从 GitHub 上扣了一个 LangGraph4j 的多 Agent 项目下来，自己魔改很多地方放进简历；视频分享平台直接用的山羊的项目。
- 主要还是能说清自己的项目；具体做没做、改没改无人在意，能回答上来项目的深挖就是做过。个人认为 AI 时代背景下，不用一行一行敲代码去理解代码，更多应该是对架构、对方案的把握；程序员更多贴近产品经理的定位，才能拉开与 AI 的重合度。

## 六、面试篇：你可以失误无数次，面试官失误一次

> 「你可以失误无数次，但是面试官失误一次就会把你招进去！」

**什么时候可以面试？为什么没人搭理我？**

- 简历写完就可以开始投，第一次就海投。正常在 BOSS 上打 100 个招呼能有一个面试都难，不用管是什么公司，投就完了，可以适当上工具解放双手；吐槽没约面时，先展示打招呼 1000+ 的页面。
- 和负责招聘的朋友聊：一个大厂岗位开放两天就能收到一千多份简历，HR 根本看不过来，只能按标签继续筛。

**为什么官网投了好久没消息？**

- 等两周到一个月都很正常，拿到 offer 的人简历也会挂一整页；很多时候是因为不完全匹配。

**面试经验**：

- 建议阶梯式面试：小厂练手，冲中厂大厂。练的是语言组织、怎么表达、怎么埋钩子、怎么自我介绍、反问问什么，尽量形成习惯，每次都这么说。
- 埋钩子很重要：不要跟着面试官走，要主动引导面试官踏入你熟悉的领域；自我介绍时就提前说项目亮点，这很吃经验。
- 不会的知识点直接回答暂时还不会，不要瞎编乱答；八股答不出来可以接受，知识太多、进去都是自研根本用不上，更多是思想层面要懂；算法撕不出来问题就有点大，平时多沉淀。
- 面试之后多复盘，成长总在复盘后：面试时手机录音，后面打开飞书整理；自己去面一场，比看十篇面经好得多，这是最真实无损无改编的经历，不要只看面试结果，无论好坏都有收获。
- 面试官很多场面试的问题基本一样，可以找面经；但提醒：面经在挂了之后再发，HR 和面试官看见会很困扰，还可能要重新准备题、找到把你直接挂了；大家多分享是好的，要注意时机。
- 面试很看经验：面过很多小厂，面大厂之前照样会紧张，因为没见过，人总是对未知事物恐惧。无论结果，勇敢迈出第一步。

## 七、对自己可用的部分

结合自己「考研为主、就业并行」的定位，这篇存档先取下面几条：

- **算法路径**：时间充足时按模块走灵神题单打基础；临考再转 Hot 100 + CodeTop，三遍刷题法可直接用。
- **简历结构**：一张纸、岗位匹配优先、校园经历和自我评价不写、优化点配前后对比数据；多岗位分版本。
- **项目表达**：准备「痛点 → 优化 → 方案对比 → 前后数据」这套问答骨架，面试结合场景深挖。
- **投递节奏**：简历定稿即可海投，按小厂 → 中厂 → 大厂阶梯练表达；每场面试录音复盘。
- 语言选择、外卖点评避雷、社招心态这些，等就业线正式启动时再对照当前 JD 复核。

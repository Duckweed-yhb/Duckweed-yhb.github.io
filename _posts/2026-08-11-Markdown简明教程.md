Markdown 是一种轻量级纯文本标记语言，只用基础键盘符号就能完成排版，不涉及字体、颜色等样式，跨设备渲染效果一致。这篇整理了常用语法和一篇博客的实战范例，适用于 GitHub 文档、个人博客和笔记软件。

## 一、基础语法对照表
| Type | Or | ... to Get |
| ---- | ---- | ---- |
| `*Italic*` | `_Italic_` | *Italic* |
| `**Bold**` | `__Bold__` | **Bold** |
| `# Heading 1` | `Heading 1`<br>`=========` | # Heading 1 |
| `## Heading 2` | `Heading 2`<br>`--------` | ## Heading 2 |
| `[Link](http://a.com)` | `[Link][1]`<br>`[1]: http://b.org` | [Link](http://a.com) |
| `![Image](http://url/a.png)` | `![Image][1]`<br>`[1]: http://url/b.jpg` | 图片嵌入 |
| `> Blockquote` | | > Blockquote |
| `* List`<br>`* List`<br>`* List` | `- List`<br>`- List`<br>`- List` | - List<br>- List<br>- List |
| `1. One`<br>`2. Two`<br>`3. Three` | `1) One`<br>`2) Two`<br>`3) Three` | 1. One<br>2. Two<br>3. Three |
| Horizontal rule:<br>`---` | Horizontal rule:<br>`***` | Horizontal rule: 分割线 |
| `` `Inline code` with backticks `` | | `Inline code` with backticks |
| ```
# code block
print '3 backticks or'
print 'indent 4 spaces'
``` | ```
# code block
print '3 backticks or'
print 'indent 4 spaces'
``` | 代码块渲染 |

#### 1.1 基础语法完整对照表
| Type | Or | ... to Get |
| ---- | ---- | ---- |
| `*Italic*` | `_Italic_` | *Italic* |

| `## Heading 2` | `Heading 2`<br>`--------` | ## Heading 2 |
| `[Link](http://a.com)` | `[Link][1]`<br>`[1]: http://b.org` | [Link](http://a.com) |
| `![Image](http://url/a.png)` | `![Image][1]`<br>`[1]: http://url/b.jpg` | 图片嵌入 |
| `> Blockquote` | | > Blockquote |

| `` `Inline code` with backticks `` | | `Inline code` with backticks |

# 计算机自学路线

我是电气工程专业的学生，和计算机科学没有直接的专业关系。但无论学什么工科，编程都已成为像数学一样的基础能力。这篇从一个"非科班但需要编程"的视角，梳理一条自学路线——目标不是成为顶尖程序员，而是**用编程解决你本专业的问题**。

## 一、先想清楚：你学编程是为了什么？

| 你的目标 | 核心语言/工具 | 典型场景 |
|----------|-------------|---------|
| 数据处理与分析 | Python + NumPy/Pandas/Matplotlib | 实验数据处理、统计建模 |
| 嵌入式/硬件控制 | C / C++ | 单片机编程、底层驱动 |
| Web应用开发 | Java + Spring / JavaScript + Vue | 企业系统、管理平台 |
| 科学计算与仿真 | MATLAB / Python | 电力系统计算、数值分析 |
| 自动化办公脚本 | Python | 批量文件处理、报表生成 |

**不走弯路的秘诀：先锚定一个具体目标，不要同时学五门语言。**

## 二、第一阶段：C语言 — 理解计算机的思维方式

无论最终用什么语言，都建议从 C 开始：它足够底层（指针让你真正理解"内存"）、足够简单（语法核心不到 50 个关键字）、足够通用（嵌入式、操作系统、高性能计算都离不开它）。

**自学路径（约 2-3 周）**

1. 数据类型 → 输入输出 → 运算符（2天）
2. 分支结构（if/switch）+ 循环结构（for/while）（2天）
3. 数组 + 字符串（2天）
4. **指针**（C 语言的分水岭，花 3-4 天集中攻克）
5. 函数 + 结构体（2天）

我博客里有完整的 C 语言 8 章笔记（👉 [C 语言入门笔记](/c-language-notes/)），每章附可运行代码和常见错误解析。

## 三、第二阶段：选择第一门主力语言

C 语言帮你建立底层认知，接下来选一门"干活的语言"深耕。

### Python（推荐指数 ⭐⭐⭐⭐⭐）

适合：数据处理、自动化、科学计算方向

| 学习模块 | 预计时间 | 关键内容 |
|----------|---------|---------|
| Python基础 | 1周 | 数据类型、循环、函数、文件读写 |
| NumPy | 3天 | 多维数组运算、矩阵操作 |
| Pandas | 1周 | 数据清洗、分组聚合、表格处理 |
| Matplotlib | 3天 | 折线图、散点图、论文级图表 |
| 项目实战 | 2周 | 用你本专业的数据跑一个完整分析 |

### Java（推荐指数 ⭐⭐⭐⭐）

适合：后端开发、企业级应用方向

学习路线：Java基础 → 面向对象（封装/继承/多态）→ 集合框架 → IO流 → Spring Boot入门

**避坑提醒**：不要一上来就学 Spring Boot，先把 Java 面向对象基础打扎实，否则框架的注解对你来说就是魔术。

## 四、第三阶段：数据结构与算法（够用就好）

非科班生不需要刷穿 LeetCode，但以下内容必须掌握：

| 必须掌握 | 了解即可 |
|----------|---------|
| 数组、链表 | 图、并查集 |
| 栈、队列 | 动态规划 |
| 哈希表 | 高级树结构 |
| 二叉树（基础遍历） | 字符串算法 |
| 排序（快排、归并） | 位运算 |
| 递归思想 | |

推荐平台：[LeetCode](https://leetcode.cn/)，从「简单」标签开始，每天 1-2 题，重在理解思路而非数量。

## 五、第四阶段：构建项目能力

### 1. Git 版本控制（1天速成）
```bash
git init                      # 初始化仓库
git add .                     # 暂存所有更改
git commit -m "描述改动"       # 提交
git push origin main          # 推送到远程
git pull                      # 拉取远程更新
```
掌握这五条命令，足够应对 90% 的个人项目场景。

### 2. 阅读文档的能力
- 遇到报错 → 看报错信息，不是直接复制到百度
- 用官方文档代替 CSDN（尤其 Python，[docs.python.org](https://docs.python.org/zh-cn/3/) 中文文档质量已经很高）
- 学会在 [Stack Overflow](https://stackoverflow.com/) 用英文关键词搜索

### 3. 从零搭一个完整项目
不要停留在"跟着教程敲一遍"。找一个小问题，从设计到编码到调试完整走一遍：
- 用 Python 写一个成绩分析脚本，读取本专业实验数据并生成图表
- 用 Java 写一个课程表管理小程序
- 用 C 语言实现一个简单计算器（带括号优先级）

## 六、计算机科班的核心基础课（有精力可选修）

| 课程 | 重要性 | 说明 |
|------|--------|------|
| 计算机组成原理 | ⭐⭐⭐⭐ | 理解CPU/内存/IO如何协作 |
| 操作系统 | ⭐⭐⭐⭐ | 进程、线程、内存管理 |
| 计算机网络 | ⭐⭐⭐ | TCP/IP、HTTP协议 |
| 数据库原理 | ⭐⭐⭐ | SQL、索引、事务 |

这些课不需要全部啃完，按需选择。如果你是电力系统方向，我更推荐把有限的课外时间优先投给 MATLAB 仿真和电力系统专业课程。

## 七、常见自学误区

1. ❌ **收集癖**：收藏 100G 网盘资料，打开过的不到 1G
   ✅ 找一套靠谱课程（B站黑马/尚硅谷），坚持看完并动手敲每一行代码

2. ❌ **完美主义**：一定要把语法全学完才开始写项目
   ✅ 学完循环和函数就可以开始写小项目，遇到不会的语法现查

3. ❌ **闭门造车**：一个人闷头学，从不和别人交流
   ✅ 加一个编程学习群、参加一次 Hackathon、把代码传到 GitHub 上

## 写在最后

编程不是目的，是工具。会 Python 意味着你能用代码做数值分析，会 C 语言意味着你能玩转单片机，会 MATLAB 意味着你的仿真效率远超纯手算的同学。

计算机自学路上最好的心态是：**我不是在转行，我是在给我的专业装上翅膀。**

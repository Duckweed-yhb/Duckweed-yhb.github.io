# C 语言代码规范

## 前言

代码是写给人看的，只是顺便让机器运行。同一个功能，写得好不好读，差别巨大——尤其当你几个月后回来看自己的代码时，这种感觉会更强烈。

这篇笔记整理自 [CS50 的 C 语言代码风格指南](https://cs50.readthedocs.io/style/c/)，是我认为最实用的一套 C 语言规范。遵循它，你的代码会清晰、统一、专业。

---

## 一、行长度

一行代码**不要超过 100 个字符**（理想是 80 字符以内）。如果超过，说明你的变量名太长，或者设计需要重新考虑。

```c
// 错误：一行太长，读者需要横向滚动
int first_collected_integer_value_from_user = get_int("Integer please: ");

// 正确：拆解或缩短命名
int first = get_int("Integer please: ");
```

---

## 二、注释

注释回答两个问题：**这段代码做什么？为什么这么做？**

关键规范：

1. 注释放在代码**上方**，而不是行尾
2. `//` 后**空一格**再写内容
3. 注释首字母大写
4. 每个文件顶部加一句总结，每个函数（除 main）顶部加一句说明

```c
// Convert Fahrenheit to Celsius
float c = 5.0 / 9.0 * (f - 32.0);
```

错误示范：

```c
//Convert Fahrenheit to Celsius      // 缺少空格
float c = 5.0 / 9.0 * (f - 32.0);   // 注释放行尾
```

## 三、头文件按字母序排列

```c
#include <cs50.h>
#include <stdio.h>
#include <string.h>
```

字母序排列，长列表里一眼就能看出是否重复或遗漏。

## 四、条件语句

```c
if (x > 0)
{
    printf("x is positive\n");
}
else if (x < 0)
{
    printf("x is negative\n");
}
else
{
    printf("x is zero\n");
}
```

要点：

- 花括号各占一行，对齐清晰
- `if` 后有一个空格
- `(` 后和 `)` 前不加空格
- `>` 和 `<` 两边各一个空格
- 内容缩进 4 个空格

---

## 五、switch 语句

```c
switch (n)
{
    case -1:
        printf("n is -1\n");
        break;
    case 1:
        printf("n is 1\n");
        break;
    default:
        printf("n is neither -1 nor 1\n");
        break;
}
```

每个 `case`（包括 `default`）都要以 `break` 结束。

## 六、函数

`main` 必须这样声明：

```c
int main(void)
{
}
```

或者带参数时：

```c
int main(int argc, char *argv[])
{
}
```

**绝对不要**写 `void main()` 或 `int main()`——这是 C11 标准不允许的。

自己的函数同理：花括号各占一行，返回类型和函数名同一行。

---

## 七、缩进

一律缩进 **4 个空格**。如果用 Tab 键，确保编辑器把 `\t` 转换成 4 个空格——否则换台电脑代码可能就乱套了。

```c
for (int i = 0; i < argc; i++)
{
    for (int j = 0, n = strlen(argv[i]); j < n; j++)
    {
        printf("%c\n", argv[i][j]);
    }
    printf("\n");
}
```

## 八、循环

### for 循环

临时迭代变量依次用 `i`、`j`、`k`。超过三个？说明设计该重想了。

```c
for (int i = 0; i < LIMIT; i++)
{
    for (int j = 0; j < LIMIT; j++)
    {
        for (int k = 0; k < LIMIT; k++)
        {
            // Do something
        }
    }
}
```

### while 循环

```c
while (condition)
{
    // Do something
}
```

### do…while 循环

```c
do
{
    // Do something
}
while (condition);
```

## 九、指针

`*` 要写在**变量名**旁边，不是类型旁边：

```c
int *p;    // 正确
int* p;    // 错误
```

声明指针和普通变量分开写，不要混在一行：

```c
int *p;
int n;
```

不要这样：

```c
int *p, n;    // 容易误解
```

---

## 十、变量

- 变量在**需要时**才声明，而不是全堆在函数开头
- 作用域尽可能小——循环变量就声明在循环里
- 变量名要具体：求和叫 `sum`，就绪状态叫 `is_ready`
- 多个单词用下划线连接（`is_ready`）

```c
for (int i = 0; i < LIMIT; i++)
{
    printf("%i\n", i);
}
```

声明多个变量时，要么都不初始化，要么都初始化：

```c
int quarters, dimes, nickels, pennies;           // 正确
int quarters, dimes = 0, nickels = 0, pennies;   // 错误：部分初始化
```

---

## 十一、结构体

```c
typedef struct
{
    string name;
    string dorm;
}
student;
```

如果结构体里有指向同类型的指针，用同名结构体标签：

```c
typedef struct node
{
    int n;
    struct node *next;
}
node;
```

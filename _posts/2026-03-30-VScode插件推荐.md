这是我整理的 VS Code 一站式插件清单，适配 LaTeX、Python、Java 开发及 Git 版本控制，插件精准实用、无冲突，搭配配置文件使用可彻底告别插件干扰，提升开发效率。

### 插件清单概览
- **LaTeX 插件**：编译、预览、语法检查，适配论文写作
- **Python 插件**：语法补全、调试、Notebook 支持，适配数据分析与开发
- **Java 插件**：语言支持、调试、项目管理，适配后端开发
- **Git 插件**：提交历史、行级追溯，适配版本控制
- **通用工具**：提升开发舒适度，全场景适配

## LaTeX
- LaTeX Workshop：LaTeX 编译、预览、语法检查、自动补全
- LTeX - Language Tool：中英文拼写与语法检查
- PDF Viewer：内置 PDF 预览
- Markdown All in One：Markdown 编辑增强

## Python
- Python：官方核心插件，语法、补全、调试
- Pylance：智能提示、类型检查
- Jupyter：Notebook 编辑与运行
- Debugpy：Python 调试引擎
- autoDocstring：自动生成函数注释
- isort：导入包自动排序

## Java
- Language Support for Java(TM) by Red Hat：Java 语言支持、补全
- Debugger for Java：Java 调试
- Test Runner for Java：单元测试运行
- Maven for Java：Maven 项目与依赖管理
- Spring Initializr：快速创建 Spring Boot 项目

## Git
- Git Graph：Git 提交历史可视化
- GitLens：行级提交追溯、查看作者与日志
- GitHub Pull Requests and Issues：GitHub PR 与任务管理

## 通用工具
- 简体中文语言包：VS Code 界面汉化
- GitHub Copilot：AI 代码补全
- Better Comments：注释高亮美化
- Code Spell Checker：英文拼写检查
- Indent Rainbow：缩进彩虹高亮
- Todo Tree：TODO 注释统一管理

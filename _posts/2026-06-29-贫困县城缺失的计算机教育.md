# 县城的计算机课

我来自河南鲁山，一个普通的县城。从小学到高中，我的计算机教育只有两个字：**缺失**。

小学没有计算机课；初中有一间机房，却是 2008 年采购的 XP 老爷机，开机五分钟，键盘字母磨光，信息技术课的"考试"是默写"计算机由哪五部分组成"；高中信息技术课直接被高考科目挤占。我直到大一下学期才真正接触编程，而很多大城市的同学初中就在用 Python 写爬虫了。

这不是抱怨，而是想从一个亲历者的角度，说说县城计算机教育的缺失有多严重、带来什么后果、我们能做点什么。

## 一、缺失的全貌：硬件、师资、课程与观念

**硬件**：机房电脑多是政府采购淘汰品，配置停在十年前；操作系统多为盗版 XP 或 Win7；网络要么没有、要么限速；维护跟不上，一半以上电脑是无法使用的摆设。

**师资**：信息技术课老师通常不是计算机专业出身，可能是数学老师转岗或临近退休的老教师，不会写代码，甚至不太会用 Excel 函数。这不能怪老师——县城工资留不住计算机专业毕业生，在郑州做程序员月薪至少六千，在县城教信息技术月薪两千出头。

**课程内容**：和十年前几乎没有变化——计算机五大组成部分、Word 打字排版、Excel 简单表格、PowerPoint 幻灯片。外面已经历了移动互联网、AI、大模型三轮浪潮，县城课堂还停留在"把字体调成红色"。

**观念**：最深的鸿沟在这里。在县城，编程被视为"和高考无关的杂事"，学生时间必须 100% 投入高考科目，学一小时 Python 等于浪费一小时刷题；而在大城市，编程是"素质教育"的一部分，父母会主动报班、买设备。

## 二、缺失的后果：不只是少一门课

**信息差的代际传递**：编程不只是一项技能，更是一个信息入口——学编程会接触 GitHub、Stack Overflow、技术博客、开源社区这些高质量信息源。从未接触编程的学生，连这些信息源的存在都不知道。更麻烦的是，信息差会代际传递：县城父母、老师都不知道"这条路可以走"，孩子只能重复刷题、高考、选个"听说好就业"的专业、找份不知道喜不喜欢的工作。

**自信心的隐性损伤**：大学课堂上，当大城市同学熟练敲代码、讨论框架时，县城学生甚至分不清"编译器"和"解释器"。这种差距会让人本能地自我怀疑："是不是我脑子不如别人？" 其实不是——**差的不是智商，是时间**，是别人比你早接触了六年。

## 三、可行的改善思路

**短期：用最低成本打破信息壁垒**
1. 一个能上网的机房就够了：不需要新电脑，只要网络通畅，学生就能接触菜鸟教程、B 站免费课程、LeetCode——质量远超任何县城教材。
2. 一个懂编程的志愿者就够了：每所县城中学对接一名大学生志愿者（线上），每周花一小时带感兴趣的学生入门 Python，成本几乎为零，对一个孩子的改变却可能是颠覆性的。
3. 把"编程体验日"带进县城：学生社团利用寒暑假组织短期体验活动，不必系统教学，只让县城孩子知道"编程是什么"，就足以埋下一颗种子。

**中长期：观念层面需要改变**
1. 让家长和老师看到案例：在信息匮乏的环境里，一个具体的成功案例比一百篇新闻报道更有说服力。
2. 改变信息技术课的考核方式：从"默写计算机组成"变成"写一个能跑的小程序"，考核标准变了，教学内容和态度自然会变。

## 四、我自己的经历

我大一下学期才开始学 C 语言，第一次敲出 `printf("Hello World")` 时，花了十分钟才搞明白为什么没输出——因为没装编译器。

这个起点低得说出来可能没人信。但我用一个寒假把 C 语言八章核心语法从头到尾敲了一遍（👉 [C语言知识总结](/c-language-notes/)），后来学了 Python、Java、LaTeX，用 Jekyll 搭了这个博客，用 GitHub Actions 实现自动部署。

**起点低不可怕，可怕的是不知道自己可以出发。** 对和我一样从县城走出来的学生，我最重要的建议是：尽早开始学编程——不是因为它万能，而是因为它是当下最便宜、最公平的"翻身工具"：你只需要一台能上网的电脑和自己的时间。

## 写在最后

二十年后的鲁山一中，信息技术课会是什么样子？我希望到那时，县城的孩子不用等到大学才第一次接触编程，每个对计算机感兴趣的孩子都能在中学时代得到最基本的启蒙——不是因为政策要求，而是因为有人告诉他们：这条路可以走。

如果你有能力也有意愿做点什么——去县城支教一个暑假、做个免费入门教程、或只是转发这篇文章——你都在帮助缩小这道信息鸿沟。

> 教育的差距，本质上是信息差。缩小信息差，从让一个县城的孩子知道"编程是什么"开始。

> —— Duckweed

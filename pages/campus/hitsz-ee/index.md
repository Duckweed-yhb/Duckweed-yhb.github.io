## 学分构成：175.5 分怎么摊开

按学校公布的专业白皮书（2021 版口径；2025 级执行方案以教务系统为准）：

| 模块 | 学分 | 里面是什么 |
|---|---|---|
| 通识教育课程 | 52 | 思政、体育、外语、文化素质类 |
| 数学与自然科学基础 | 32.5 | 高数、线代、概率、大学物理及实验 |
| 专业教育课程 | 89 | 技术基础课、专业核心课、专业必修、选修、实习实训、毕业设计 |
| 创新学分 | 2 | 大创、学科竞赛、论文专利等认定 |
| **合计** | **175.5** | |

专业课里真正决定你「会不会」的，是这四组：

- **技术基础**：电路、模拟电子技术基础、数字电子技术基础、电磁场，加三门配套实验。
- **专业核心**：电机学、电力电子技术、自动控制理论、电力系统基础。
- **专业必修**：高级语言程序设计、DSP 的原理与应用、信号与系统、工程制图基础、机械设计基础、电气前沿技术专题。
- **实训链条**：认知实习 → 金工实习 → 电子工艺实习 → 技术基础课程设计 → 专业课程设计 → 专业创新设计 → 生产实习 → 毕业设计。

一条经验：这条实训链条是本校电气最值钱的部分，但收益取决于你**提前**会不会用工具。同一块板子，会焊接、会画原理图、会用示波器的人两小时收工，不会的人两周还在查接线。

## 升学与就业

先给判断，再给理由。

**保研**：绩点是硬门槛，不是加分项。专业课里电路、模电、数电、电机学、电力电子、自控这六门权重最高——它们同时是复试笔试和面试的高频区。科研与竞赛拉开差距，但替代不了绩点。名额与细则每年调整，只认教务部与学院当年口径。

**考研**：本专业常见去向包括本校与哈工大本部、清华、浙大、西交、华科、东南等，专业课多为「电路」或「电气工程基础」——**各校差异很大，务必查目标院校当年招生目录与考试大纲**。

**就业**：深圳一带与本专业对口的方向大致五类，只列方向与代表企业，不代表录用难度：

| 方向 | 做什么 | 常见去处（举例） |
|---|---|---|
| 电力电子与电源 | 逆变器、变换器、充电与储能电源 | 汇川技术、麦格米特、英威腾 |
| 新能源与电池 | BMS、电驱、储能系统 | 比亚迪、欣旺达 |
| 无人机与机器人电控 | 电机驱动、运动控制 | 大疆 |
| 数字能源 | 光伏逆变、数据中心供电 | 华为数字能源 |
| 电网与设计院 | 调度、继保、配电设计 | 南方电网、深圳供电局、电力设计院 |

一句实话：想稳，走电力系统方向去电网与设计院；想动手做产品、接受节奏快，电力电子与电力传动方向在深圳的机会更多。

## 六条我踩过的坑

1. **「学过」不等于「会」。** 电路实验接线错一次，胜过看十页书。判断标准：能不能不看答案从头做出来。
2. **绩点是硬门槛。** 别用「能力比绩点重要」安慰自己，保研看排名，排名只认分数。
3. **英语不是门槛，是速度。** datasheet 全英文，四级 445 分也读得动，只是慢，练两个月就够用。
4. **信息差最贵。** 培养方案、竞赛通知、实验室招人、夏令营，全在官网和年级群里，没人主动通知你。
5. **收藏不等于学会。** 这个站的价值在「路线」，不在链接数量。
6. **四年不必线性。** 休学、转专业、重修都正常，节奏乱了可以重排；把「我落后了」当结论，才是最贵的误判。

## 这套页面还缺什么

诚实列出来，避免有人把没写的地方当成「不重要」：

- **逐学期课表与学分**：2025 级执行方案 PDF 的附件下载需要验证码，我没有逐条录入。上面十二页的课程是「学年集合 + 季节侧重」的写法，不是官方切分。
- **各课任课教师、考核方式与历年难度**：没有可靠来源，不编。
- **实验室与导师名单、进组方式**：待补。
- **近年保研名额与细则**：逐年变化，需按当年文件更新。
- **夏季学期的实际安排**：短学期各年级开什么、是否强制，以校历与教务通知为准。

如果你是同专业的同学，欢迎到仓库提 Issue 补上任何一条，或者直接提 PR。这套页面的目标不是写全，是每一条都能被后来的人验证。

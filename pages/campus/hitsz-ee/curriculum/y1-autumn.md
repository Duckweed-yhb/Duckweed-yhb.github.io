# 大一秋 · 换挡期

> **定位：换挡期。** 从「被安排」到「自己排」，从刷题到证明。这学期没有一门课是「难的」，但所有人都在这里掉队。

## 这学期的课

参考分布（学年集合；学期切分以教务系统为准）：

| 课程 | 类别 | 这学期该拿到什么 |
|---|---|---|
| 高等数学（1） | 数理基础 | 从「会算」转到「会证」，极限与导数定义要能自己写出来 |
| 线性代数 | 数理基础 | 矩阵运算、秩与线性相关；别只记公式，画得出几何意义 |
| 大学物理（1） | 数理基础 | 力学与刚体；矢量语言从此开始 |
| 高级语言程序设计 | 专业必修 | C 的指针、数组、结构体，能写能调 |
| 工程制图基础 | 专业必修 | 三视图与尺寸标注，后面画板、看机械图都靠它 |
| 通识 / 军训 / 体育 | 通识 | 别挂科，别让绩点在大一就定死 |

## 主线：把「数学密度」适应过来

大学第一学期的真实难度不在内容，在**节奏**：一周推进课本 30 页，没人等你。适应不了，后面每学期都会欠账。

具体到动作，只有一件：**每周日花 40 分钟，把这周的板书重写成自己的话。** 写完能对着它讲 5 分钟，就算这周过关。这件事看起来笨，但它是后面所有课的复利。

## 唯一验收

> 合上所有资料，手写一段 100 行以内的 C 程序（含指针与结构体），并在纸上标出每个变量在内存里的位置。

做不到就重做，别进入下一章。指针没打通，后面 DSP、嵌入式、驱动全是空中楼阁。

## 接哪个板块

- [01 数理与编程基础](https://duckweed-yhb.github.io/eediy/01-math-programming/README)：高数、线代、C 语言三门正好对位。
- [08 硬件工具链](https://duckweed-yhb.github.io/eediy/08-hardware-toolchain/README)：这学期只做一件事——装好 VS Code 与 Git，每次作业建一个仓库。

具体到公开课：C 语言跟 [CS50x](https://duckweed-yhb.github.io/eediy/01-math-programming/README) 前 5 周最省力，它逼你交作业；高数卡壳时看 MIT 18.01SC 的同一小节，只补直觉不补题量。

## 三个坑

1. **用高中方法学高数。** 刷题能过考试，但过不了后面的信号与控制——那两门要的是「能推」。
2. **C 语言当文科背。** 看得懂 ≠ 写得出。判断标准只有一个：能不能不看答案从空白文件开始写。
3. **把绩点不当回事。** 大一课程权重高、拉分容易，这是四年里最容易攒绩点的一年。

## 学期末自检

- [ ] 高数（1）的定理能自己复述证明思路，而不是只记结论。
- [ ] 能不看答案写出含指针交换、结构体数组的 C 程序，并解释每行在内存里发生了什么。
- [ ] 有一个属于自己的 Git 仓库，且这学期的作业都在里面。

# 大三秋 · 分水岭上半年

> **定位：分水岭上半。** 这学期第一次同时面对「系统」和「频域」：电机是系统，自控是语言。学得动的人从这里开始拉开差距。

## 这学期的课

参考分布（学年集合；学期切分以教务系统为准）：

| 课程 | 类别 | 这学期该拿到什么 |
|---|---|---|
| 电机学 | 专业核心 | 变压器、异步机、同步机的等效电路与转矩；dq 变换的物理来源 |
| 自动控制理论 | 专业核心 | 传递函数、稳定性、根轨迹、频域校正（Bode/Nyquist） |
| 电力系统基础 | 专业核心 | 视方案安排；潮流、短路、稳定的物理含义 |
| DSP 的原理与应用 | 专业必修 | TMS320 系列的定点/浮点、外设、中断；会算溢出 |
| 信号与系统 | 专业必修 | 卷积、傅里叶、拉氏、采样定理 |
| 电气前沿技术专题 | 专业必修 | 听方向、认老师、找选题的窗口 |
| 技术基础课程设计 | 实践 | 第一次按工程要求交付（有指标、有报告） |

## 主线：把「课」翻译成「模型」

大三上的课有一个共同点：**它们都是对同一个物理世界的不同视角**。电机学讲能量转换，自控讲行为调节，信号讲信息表达。三门课串起来，你才有能力做真正的控制。

具体动作：挑一台小电机（或仿真模型），把它的参数、方程、传递函数、控制框图连成一张图，图上每一块都标注来自哪门课。这张图画得出来，说明你真的打通了。

## 唯一验收

> 手推一次 Park 变换（从三相 abc 到 dq），并解释为什么变换后转矩只与 q 轴电流成正比；再用仿真验证 dq 下的电流环阶跃响应。

## 接哪个板块

- [04 电机与运动控制](https://duckweed-yhb.github.io/eediy/04-motor-control/README)：电机学、自控、FOC 的主线，是本校专业课最对口的板块。
- [06 信号与通信](https://duckweed-yhb.github.io/eediy/06-signal-communication/README)：信号与系统、频域分析、采样与滤波。
- [03 嵌入式与单片机](https://duckweed-yhb.github.io/eediy/03-embedded-mcu/README)：DSP 那门课的现实版就是它。

## 三个坑

1. **电机学只背公式。** 不把 dq 想成「换个坐标系看同一个磁场」，后面 FOC 就是一堆符号。
2. **自控只画根轨迹。** 不会整定，不会看带宽与相位裕度，等于没学。
3. **信号与系统往后拖。** 它是控制、电力电子、通信的共同语言，越拖越贵。

## 学期末自检

- [ ] 能解释「为什么电流环带宽要远高于速度环」。
- [ ] 能看懂一份逆变器/驱动芯片 datasheet 的关键参数（开关频率、死区、驱动电流）。
- [ ] 有一份自己整理的「电机—控制—信号」三联图。

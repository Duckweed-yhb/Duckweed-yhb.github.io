# 大二春 · 电路下半年

> **定位：电路年下半。** 从模拟跨到数字，从「搭电路」跨到「画板子」。这学期结束时，你应当能独立做一块能用的板。

## 这学期的课

参考分布（学年集合；学期切分以教务系统为准）：

| 课程 | 类别 | 这学期该拿到什么 |
|---|---|---|
| 电路（2） | 技术基础 | 正弦稳态、三相、暂态与频率响应 |
| 数字电子技术基础 | 技术基础 | 逻辑门、组合与时序、触发器、状态机入门 |
| 模拟电子技术实验 | 实践 | 运放电路、滤波器、振荡电路的实测 |
| 数字电子技术实验 | 实践 | 门电路与计数器的搭接、时序测量 |
| 复变函数与积分变换 | 数理基础 | 拉氏变换与系统函数，衔接信号与系统 |
| 工程训练（金工实习） | 实践 | 车钳铣焊各来一遍，理解制造的边界 |

## 主线：从「搭电路」到「画板子」

大二秋你在面包板上验证想法，大二春你要把想法变成一块能打样的 PCB。这是从爱好者到工程师的第一道门。

具体动作：选一个真正有用的小电路（比如一个 5V→3.3V 供电 + MCU 最小系统 + 一个 LED 驱动），走完「原理图 → 封装 → 布局 → DRC → 打样 → 焊接 → 上电 → 排故」全流程。第一次一定有一版是废的，这很正常，废一版学到的比看十篇教程多。

## 唯一验收

> 独立完成一块两层板：能上电、能工作、DRC 无错，并且你能说出每个封装为什么选它、每条关键走线为什么这么走。

## 接哪个板块

- [02 电路与电子学](https://duckweed-yhb.github.io/eediy/02-circuit-electronics/README)：模电数电的主场。
- [07 数字逻辑与 FPGA](https://duckweed-yhb.github.io/eediy/07-digital-fpga/README)：数电学得顺的话，可以在这里提前接触 Verilog，为后面的 FPGA 留口子。
- [08 硬件工具链](https://duckweed-yhb.github.io/eediy/08-hardware-toolchain/README)：PCB 设计、DRC、打样、焊接，这一板块这学期要过完。

## 三个坑

1. **数电只背卡诺图。** 不动手搭一次计数器，你永远不知道竞争冒险是什么样。
2. **金工实习当放假。** 它教的公差、工艺、装配，是「设计能不能造出来」的判断力。
3. **PCB 直接抄别人的布局。** 抄出来的板能跑，但你不知道为什么要这么放，下一块还是不会。

## 学期末自检

- [ ] 三相电路能画相量图并算出线电流。
- [ ] 能用触发器搭出一个指定模值的计数器，并实测波形验证。
- [ ] 有一块自己画的、打样回来的板，上电工作。

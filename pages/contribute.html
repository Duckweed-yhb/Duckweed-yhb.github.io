投稿 / 贡献指南

欢迎一起建设这个学习资源共享空间 ✨

我可以贡献什么？

这个博客的主题是 电气工程学习、编程入门、大学成长经验。如果你有以下内容，欢迎投稿：

  • 📝 课程笔记补充或纠错（尤其是电气工程专业课）
  • 💡 学习经验分享（考研、实习、竞赛、科研）
  • 🛠️ 工具使用教程（MATLAB、Simulink、PSCAD、LaTeX等）
  • 📖 读书笔记（与学习、成长、技术相关的书籍）
  • 🐛 发现博客中的错误或过时信息

投稿方式

方式一：GitHub Pull Request（推荐）

  1. Fork 本博客仓库：Duckweed-yhb.github.io
  2. 在 _posts/ 目录下创建新文章，命名格式：YYYY-MM-DD-标题.md
  3. 参考现有文章格式添加 Front Matter（layout, title, date, categories, tags, author）
  4. 提交 Pull Request，附上简要说明

方式二：邮件投稿

将稿件发送至 3071974740@qq.com，标题注明「博客投稿」。接受 Markdown 格式或纯文本。

方式三：提 Issue

如果只是发现错误或有改进建议，可以直接在 GitHub Issues 中提出。

文章格式要求

  • 使用 Markdown 格式，参考现有博客文章的风格
  • Front Matter 必须包含 layout: post、title、date、categories、tags、author
  • 正文使用 #、## 做层级标题
  • 代码块用三个反引号包裹，标注语言类型
  • 如有图片，放在 assets/images/ 目录，命名以日期开头
  • 文末建议附上作者的简短签名或联系方式（可选）

审核与署名

  • 所有投稿将在一周内审核
  • 通过后会保留你的署名（author 字段），并在文章末尾注明贡献者
  • 内容可能需要小幅修改以统一风格，重大改动会提前沟通
  • 发布后会在博客首页的「最新笔记」中出现

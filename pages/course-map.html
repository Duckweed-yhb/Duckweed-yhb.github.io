required 必修基础 signals 信号处理 robotics 机器人 circuits 电路 power 电力 devices 器件 optics 光学

📖 逐课详解

EE 16A必修
Designing Information Devices and Systems I · 信息设备与系统设计 I
EECS 专业基础序列第一门课。通过工程应用（层析成像、电路分析、GPS定位）来讲授线性代数。核心是让你理解矩阵运算、方程组求解在实际工程中的意义。
先修：Math 54（线性代数）
EE 16B必修
Designing Information Devices and Systems II · 信息设备与系统设计 II
衔接 16A，引入微分方程、晶体管电路、稳定性与反馈控制、SVD/PCA。最终项目是 SIXT33N 声控小车实验，将整条课程线贯穿起来。是 16A 到高阶课程的桥梁。
先修：EE 16A
EE 105电路
Microelectronic Devices and Circuits · 微电子器件与电路
模拟集成电路的基础课。覆盖半导体物理基础、p-n结、MOS电容器、MOSFET大信号模型、单级与多级CMOS放大器、频率响应。是 EE 140/142 的先修课，模拟IC设计的入门。
先修：EE 16A, 16B
EE 120信号
Signals and Systems · 信号与系统
连续时间和离散时间信号与系统的数学分析。核心内容：卷积、傅里叶级数、傅里叶变换、拉普拉斯变换、采样定理。是所有信号处理相关方向的必修基础课。
先修：EE 16A, 16B
EE 126信号
Probability and Random Processes · 概率与随机过程
面向工程应用的概率论与随机过程。覆盖：随机变量、随机过程、马尔可夫链、估计理论。是通信、机器学习、控制方向的数学工具箱。
先修：EE 16A, 16B
EE 130器件
Integrated-Circuit Devices · 集成电路器件
深入半导体器件物理：能带理论、载流子输运、PN结、BJT、MOSFET的器件级建模与分析。相较于 EE 105 更偏器件层面，适合想走向芯片设计和半导体物理方向的学生。
先修：EE 16A, 16B
EE 134光学
Fundamentals of Photovoltaic Devices · 光伏器件基础
光伏（太阳能电池）器件的入门课程。涵盖光伏效应、太阳能电池的工作原理、效率分析、新材料和新技术。偏向新能源方向和器件物理的交叉。
先修：EE 16A, 16B
EE 137A电力
Introduction to Electric Power Systems · 电力系统导论
电力系统的经典入门课。覆盖三相电路、变压器、输电线路模型、潮流计算、故障分析、电力系统经济调度。是电气工程电力方向的必修核心课程，与国内电气专业的电力系统分析内容高度重合。
先修：EE 16A, 16B
EE 137B电力
Introduction to Electric Power Systems II · 电力系统导论 II
聚焦现代电力系统的新兴技术：电力电子在配电网的应用、光伏/风力发电并网、储能系统、微电网、需求侧响应。比 137A 更偏前沿和实际工程。
先修：EE 137A
EE 140电路
Linear Integrated Circuits · 线性集成电路（模拟IC设计）
模拟集成电路设计的核心课程。在 EE 105 的基础上深入学习运算放大器、反馈放大器、频率补偿、噪声分析、版图设计。是模拟IC方向的核心实践课。
先修：EE 105
EE 142电路
Integrated Circuits for Communications · 通信集成电路
射频和通信集成电路设计。覆盖低噪声放大器(LNA)、混频器、振荡器、锁相环（PLL）等射频前端模块的电路实现。适合通信+电路交叉方向。
先修：EE 105
EE 143器件
Microfabrication Technology · 微纳加工技术
半导体制造工艺的实践课程。在超净间（cleanroom）中进行光刻、刻蚀、沉积、氧化等工艺操作，亲手制作微型器件。是理解"芯片是怎么造出来的"最直观的课程。
先修：EE 16A, 16B
EE 144必修
Fundamental Algorithms for System Modeling, Analysis, and Optimization · 系统建模分析优化算法
面向嵌入式系统和信息物理系统的算法设计。覆盖：实时调度、电源管理、模型检测、嵌入式软件设计方法。适合嵌入式/物联网方向。
先修：EE 16A, 16B
EE 145B必修
Medical Imaging Signals and Systems · 医学成像信号与系统
医学成像的物理原理和信号处理方法。覆盖 X 光、CT、MRI、超声、核医学成像的数学基础。是生物医学工程方向的交叉课。
先修：EE 120
EE 145L必修
Introductory Electronic Transducers Laboratory · 传感器实验
传感器与换能器的动手实验课。设计和搭建用于测量物理量（温度、压力、光等）的电子传感系统，从电路设计到数据采集全流程。
先修：EE 16A, 16B
EE 149信号
Introduction to Embedded Systems · 嵌入式系统导论
嵌入式系统的软硬件协同设计。使用微控制器（ARM等），覆盖实时操作系统、中断处理、传感器接口、低功耗设计。是嵌入式/IoT方向的核心项目课。
先修：EE 16A, 16B
EE C106A机器人
Introduction to Robotics · 机器人学导论
机器人学的入门课程，覆盖运动学、动力学、轨迹规划、控制。使用 ROS（机器人操作系统）进行编程实验。是机器人方向的必修基础课。
先修：EE 16A, 16B；推荐 EE 120
EE C106B机器人
Robotic Manipulation and Interaction · 机器人操作与交互
聚焦机器人抓取与操作：力控制、阻抗控制、抓取规划、视觉伺服。是 C106A 的进阶课，侧重机器人与物理世界的交互能力。
先修：EE C106A

💻 计算机科学（CS）课程地图

HKN 官方先修依赖图。课程按方向用颜色区分：核心(红)、硬件(蓝)、软件(绿)、理论(紫)、应用(橙)。

core 核心必修 hardware 硬件 software 软件 theory 理论 applications 应用

📖 逐课详解

CS 61A核心
Structure and Interpretation of Computer Programs · 计算机程序的结构与解释
CS 专业的第一门编程课——但不是教你"用 Python 写 hello world"。这门课的核心是抽象思维：函数式编程、高阶函数、递归、数据抽象、面向对象编程、解释器设计。使用 Python + Scheme + SQL 三门语言，目标不是学会某门语言，而是理解编程的本质。
无正式先修（入门课）
CS 61B核心
Data Structures · 数据结构
数据结构与算法的核心课。使用 Java，覆盖：链表、树、哈希表、堆、图、排序算法、搜索算法、算法复杂度分析。课程后半段有一个大型项目（通常是用 Java 做一个完整的应用）。这是面试刷题的前置课程。
先修：CS 61A
CS 61C核心
Machine Structures · 计算机组成与体系结构
从C语言到CPU：C 和汇编语言编程、程序到机器码的翻译、计算机组成（数据通路、流水线）、缓存、性能测量、并行计算、仓库级计算。让你理解"高级代码到底是怎么在硬件上跑的"。
先修：CS 61A, 61B
CS 70核心
Discrete Mathematics and Probability Theory · 离散数学与概率论
CS 专业的数学基础课。覆盖两大块：离散数学（逻辑、归纳、数论、图论）和概率论（随机变量、分布、期望、集中不等式）。这是整个 CS 理论体系的数学地基，170、172 等理论课的绝对先修。
无正式先修（推荐微积分基础）
CS 152硬件
Computer Architecture and Engineering · 计算机体系结构
进阶处理器设计：超标量、乱序执行、分支预测、多核、内存一致性、GPU 架构。使用 Verilog/VHDL 进行 RTL 设计。是 CPU 设计方向的核心课。
先修：CS 61C
CS 160软件
User Interface Design and Development · 用户界面设计
人机交互（HCI）入门。覆盖：用户研究、原型设计、可用性测试、移动端交互设计。包含一个贯穿全学期的 App 设计项目。
先修：CS 61B
CS 161软件
Computer Security · 计算机安全
信息安全核心课。覆盖：内存安全漏洞（缓冲区溢出）、密码学基础、网络安全、Web 安全、认证协议、隐私。以"攻防"视角理解安全，包含 Capture The Flag（CTF）练习。
先修：CS 61C
CS 162软件
Operating Systems and System Programming · 操作系统
经典的操作系统课程。覆盖：进程与线程、同步、内存管理（虚拟内存、分页）、文件系统、I/O、分布式系统基础。包含一个完整的操作系统项目（PintOS 或 NachOS），需要大量 C 语言编程。
先修：CS 61C
CS 164软件
Programming Languages and Compilers · 编程语言与编译器
编译器设计全流程：词法分析、语法分析（LL/LR）、语义分析、中间代码生成、代码优化、目标代码生成。需要实现一个完整的编译器。理解这门课后，任何编程语言对你来说都不再是黑箱。
先修：CS 61B, 61C
CS 168软件
Introduction to the Internet: Architecture and Protocols · 互联网架构与协议
计算机网络核心课。覆盖：TCP/IP 协议栈、路由算法（BGP/OSPF）、拥塞控制、DNS、HTTP/2、软件定义网络（SDN）。与 Stanford 的 CS 144 对标。
先修：CS 61B, 61C
CS 169应用
Software Engineering · 软件工程
SaaS（软件即服务）开发的全流程。使用 Ruby on Rails，覆盖：敏捷开发、TDD/BDD、RESTful API、云部署。以团队项目形式模拟真实公司开发流程。是"离找工作最近的一门课"。
先修：CS 61B
CS 170理论
Efficient Algorithms and Intractable Problems · 高效算法与难解问题
算法设计与分析的顶峰课。覆盖：分治、动态规划、贪心、网络流、线性规划、NP完全性、近似算法。这是面试算法题的终极源头，也是计算机科学理论的核心。
先修：CS 61B, CS 70
CS 172理论
Computability and Complexity · 可计算性与复杂度
计算机科学理论基石：图灵机、不可判定性（停机问题）、复杂度类（P/NP/PSPACE）、归约。回答了"什么是计算机能计算的、什么是永远也算不出来的"这个终极问题。
先修：CS 170
CS 174理论
Combinatorics and Discrete Probability · 组合数学与离散概率
进阶组合数学：计数原理、生成函数、图论进阶、随机算法分析。是随机算法、密码学方向的数学基础。
先修：CS 70
CS 176应用
Algorithms for Computational Biology · 计算生物学算法
生物信息学核心算法：序列比对（Smith-Waterman）、后缀树/后缀数组、系统发育树、隐马尔可夫模型、RNA二级结构预测。是 CS × Bio 的交叉方向。
先修：CS 61B, CS 70
CS 184应用
Foundations of Computer Graphics · 计算机图形学基础
图形学四大模块：建模（mesh/spline）、渲染（光线追踪/光栅化）、动画（物理模拟/关键帧）、图像处理。课程包含多个编程项目，使用 OpenGL/C++。
先修：CS 61B
CS 186应用
Introduction to Database Systems · 数据库系统导论
数据库全栈：关系代数、SQL、查询优化、事务与并发控制、B+树索引、NoSQL。课程含一个用 Java 实现的简易数据库系统项目。
先修：CS 61B
CS 188应用
Introduction to Artificial Intelligence · 人工智能导论
以吃豆人（Pacman）系列项目著称的 AI 入门课。覆盖：搜索、约束满足、博弈树、马尔可夫决策过程、强化学习、贝叶斯网络、隐马尔可夫模型。相比 CS 189（机器学习）更偏"经典 AI"。
先修：CS 61A, 61B；推荐 CS 70
CS 189应用
Introduction to Machine Learning · 机器学习导论
机器学习理论的经典课程。覆盖：线性回归/分类、SVM、决策树、集成方法、神经网络、PCA、聚类、梯度下降优化。数学要求高（线性代数+概率论+优化），是 Berkeley 最具挑战性的本科课程之一。
先修：CS 70；推荐 Math 53, 54
CS 191应用
Quantum Information Science and Technology · 量子信息科学与技术
量子计算入门：量子比特、量子门、量子算法（Shor/Grover）、量子纠错、量子通信。面向 CS 专业的量子计算课程，需要线性代数和概率论基础。
先修：CS 70；推荐 Math 54

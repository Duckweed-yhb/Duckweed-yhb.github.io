未研

博客间关系建设 & 长期功能增强 · 阶段路线图

「未研」记录 Duckweed's Space 博客的迭代路线。内容优化（空文章补全、链接更新、展览页同步、标签统一）已全部完成 ✅。博客间关系建设（课程地图、导航页、系列化体系、交叉引用网络、博客地图、相关推荐）全部落地 ✅。功能增强（评论系统、TOC目录、进度条、暗黑手动切换）全部上线 ✅。以下为剩余长期设想的规划。
全部完成 博客间关系建设 · 功能增强
  • ✅
    课程地图（依赖关系可视化）
    电气工程和计算机科学课程地图，SVG 箭头可视化先修依赖，链接到对应博客文章。参考 UC Berkeley EECS 课程指南设计。
  • ✅
    导航页两层级人群细分
    高中生/准大学生/大学生 → 电气/计算机/其他/想转电气/想转计算机，10 个子分类区，每区含针对性推荐文章和指引卡片。
  • ✅
    文章系列化系统
    `_data/series.yml` 定义四个系列（电气工程/计算机入门/大学成长/高考之声），文章底部自动渲染系列导航条，显示"当前/跳转"。
  • ✅
    博客地图（全局可视化站点导览）
    SVG 网络图展示全部 22 篇博客按五大主题分组的归属关系和交叉关联，底部附文本链接列表。
  • ✅
    文章底部自动「相关推荐」
    基于 tags（权重 ×3）和 categories（权重 ×2）计算相似度，每篇文章底部自动展示最多4篇相关推荐。
  • ✅
    Giscus 评论系统
    基于 GitHub Discussions，零成本、零广告。Production 环境自动加载，repo-id 使用占位值，需从 giscus.app 配置真实 ID。
  • ✅
    TOC 悬浮目录 + 阅读进度条
    桌面端右侧悬浮自动生成 h2/h3 目录，IntersectionObserver 高亮当前位置；顶部蓝色进度条随滚动实时更新。
  • ✅
    暗黑模式手动切换
    header 右侧 🌓 按钮，应用 `html.force-dark` 类覆盖亮色样式，状态持久化至 localStorage。（Giscus 主题已配置 `preferred_color_scheme`）
🟢 博客基础设施已基本完整。课程地图 + 博客地图 + 导航页构成三层导览体系（课程先修 → 全局归属 → 人群分流），系列化系统 + 相关推荐实现自动化文章网络连接。
